# v9.53-local 版本快照

## 明细认账规则

- 明细认账规则详情页新增条件搜索，支持按关键字、关键字字段和匹配方式筛选。
- 每个明细认账条件新增“编辑条件”入口，进入独立整页编辑，只修改当前条件及其分账配置。
- 单条件编辑页复用新建/编辑明细认账规则的表单结构和交互样式，减少弹窗编辑时的空间限制。

## 页面体验

- 入账结果的入账明细列表中，收入类型、收入属性、收入部门、NC 项目名称、平台项目名称、平台项目详情、地区、匿名、会员姓名改为小字号展示；预算编码恢复正常字号。
- 日期汇总任务详情中的银行流水用途和附言支持换行显示，长内容不再只显示一小段。
- 删除整日日期汇总任务时显示删除进度；任一日期删除处理中，所有日期汇总删除按钮都会禁用，避免重复操作和误判系统无响应。

## 构建与部署包

- 前端页面改为按路由懒加载，降低首屏 JS 体积。
- 后端构建外置常用服务端依赖，`dist/boot.js` 从数 MB 级降到约 338 KB。
- 构建脚本会清理 `dist` 下的 `.DS_Store`。
- 本次没有新增依赖，`package-lock.json` 无变化；推荐部署脚本无需修改。
- 注意：优化后的运行方式依赖服务器已有 `node_modules`，不适合“只上传 dist 目录”的部署方式。

## 数据库迁移

- 本版无新增数据库迁移。
- 若线上尚未执行 v9.51，需要先执行 `migrate-v9.51-counterparty-match-accounts.sql`。

## 验证

- `npm run check` 通过。
- `npm run lint` 通过。
- `npm run build` 通过。
- `node dist/boot.js` 启动检查通过。
- `git diff --check` 通过。
