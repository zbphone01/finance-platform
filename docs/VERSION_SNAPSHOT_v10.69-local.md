# v10.69-local 版本快照

## 发布范围

- 本版本从 `v10.68-local` 升级，修复历史明细分账包删除来源订单包、删除任务并重新上传后，复用旧分账明细可能产生错误认账范围的问题。
- 尚未认账的分账明细如果引用了已被当前规则删除的条件 ID，会先按上传时固化的认账条件字段值和当前“等于”规则重新匹配；已有认账结果的历史分账明细保持不变。
- 手动关联待拆分订单后，改为按实际涉及的分账包分别启动增量认账，不再使用会排除分账子明细的普通认账范围。
- 认账队列按“任务 + 认账模式 + 分账包”区分身份；普通认账、不同分账包认账不会再因任务 ID 相同而合并并丢失 `detailSplitFileId`。
- 分账包完成前增加结果完整性校验；仍有已关联但未写入认账结果的活动分账明细时，分账包进入失败状态并展示数量，不再静默显示完成。
- 页面右上角版本号更新为 `v10.69`。
- 部署包为 `releases/finance-platform-v10.69-local.tar.gz`，包含本次验证生成的预构建 `dist/`。

## 数据库、依赖与配置

- 本版本没有数据库结构迁移，不执行 SQL，不使用 `drizzle schema push`。
- 不新增或删除表、字段、索引、存储过程和 MySQL Event。
- 不新增 npm 依赖、环境变量或运行配置。
- 从 `v10.68-local` 升级时只做部署文档中的只读数据库连通性和核心表检查。

## 验证结果

- `npm run check`、`npm test`、`npm run build` 和 `git diff --check` 均通过。
- 新增旧规则条件 ID 重匹配和认账队列范围隔离测试；全量测试覆盖通过。
- 构建生成非空 `dist/boot.js`、`dist/public/index.html` 和前端资源。
- 发布包必需构建产物、当前版本文档和禁止内容已按仓库发版规则复核。

## 风险与回退

- 旧规则条件只能按当前“等于”规则重新匹配；无法匹配的已关联分账明细会明确失败，需要先修正规则再重试。
- 队列仍保持全局串行，但普通认账和不同分账包认账不再合并，极端并发场景下可能增加排队任务数，这是为保证认账范围正确而保留的行为。
- 回退认账平台时可直接重新部署 `v10.68-local` 发布包；本版本没有数据库迁移，不执行数据库回退 SQL。
