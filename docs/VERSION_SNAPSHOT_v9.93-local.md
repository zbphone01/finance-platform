# v9.93-local 版本快照

## 发布范围

- 本版用于优化明细分账执行反馈、明细分账包匹配效率、明细分账包删除回滚，以及 T+1 订单明细认账查询路径。
- 右上角系统版本号更新为 `v9.93`。
- 部署包：`releases/finance-platform-v9.93-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 明细分账

- 明细分账菜单中，执行中的状态只通过列表状态列进度条展示，不再显示顶部文字状态提示。
- 明细分账包认账时，先批量读取候选分账条目并在内存中按匹配字段分组，再与待拆分订单明细匹配，减少重复查询。
- 删除明细分账包时，会同时清理同一拆分组产生的兄弟入账结果，并把来源订单明细恢复为待拆分状态，避免只回滚订单明细包、不完整回滚认账状态。

## 明细认账性能

- 认账开始时优先使用订单明细上传阶段已写入的任务总额和条数快照，避免先扫描 `bill_details` 统计整包金额。
- T+1 认账能定位订单明细包 ID 时，优先使用 `order_file_id` 范围配合复合索引圈定订单明细，再按规则统计和生成入账结果。
- 同日汇总模式下，会从当前任务和同日候选任务推导可参与认账的订单明细包范围，避免只按当前任务导致漏认。

## 技术说明

- 本版没有新增数据库迁移。
- 本版同步更新 `docs/finance-recon-SKILL.md`，固化订单明细上传、认账、同日汇总、明细分账删除回滚和索引优化边界，避免后续迭代误改。
