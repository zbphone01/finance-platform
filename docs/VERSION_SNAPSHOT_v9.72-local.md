# v9.72-local 版本快照

## 发布范围

- 本版用于替代 v9.71-local 包，包含本轮对话中确认的订单明细包、明细分账包、认账状态和规则编辑性能修复。
- 部署包：`releases/finance-platform-v9.72-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 订单明细包

- 删除超大订单明细包时，改为分批处理关联明细分账包，避免一次性处理百万级明细导致调用栈溢出。
- 删除订单明细包后，会同步刷新关联明细分账包汇总，避免残留旧统计。
- 订单明细包汇总统计纳入 `已拆分` 来源明细，保证列表汇总口径和明细状态一致。

## 明细分账

- 明细分账成功关联来源订单明细后，来源明细显示为 `已拆分`，比原先显示为 `已忽略` 更符合业务含义。
- 删除明细分账包后，来源订单明细可从 `已拆分` 或历史 `已忽略` 状态回滚为 `待拆分`。
- 删除明细分账包后，会重新计算来源订单明细包汇总，修复待拆分数未同步恢复的问题。
- 删除明细分账包时，前端会等待明细分账、订单明细包、认账及分账相关列表刷新后再提示完成，减少跨菜单状态延迟。

## 认账及分账

- 认账任务状态变化后，会同步重算银行流水认账状态，减少进入查看页时流水仍未更新的问题。
- 任务详情和订单明细详情支持展示 `已拆分` 状态；已认账明细仍优先显示 `已认账`。

## 明细认账规则编辑

- 编辑明细分账规则时，将分账设置区域拆成稳定组件，并稳定输入相关操作，减少输入认账关键字字段和关键字时的页面重渲染。
- 保留此前树形选择组件的延迟过滤优化，本版是在原优化基础上继续降低输入卡顿。

## 数据库迁移

- 本版不新增数据库迁移。
- 如果目标环境尚未部署 v9.70，需要先执行 `migrate-v9.70-detail-split-rule-upload-fields.sql`。
- 已执行过 v9.70 迁移的环境，直接部署 v9.72 代码即可。

## 验证

- `npm run check` 通过。
- `npm run build` 通过。
- 发布包完整性检查通过，沿用历史轻量发布方式，不包含本地 `dist`，由服务器部署脚本重新构建。
- 发布包未包含 `node_modules`、`.upload-cache`、`releases` 等本地大目录。
