# v10.08-local 版本快照

## 发布范围

- 本版用于优化打包明细订单包上传后的银行流水自动匹配和后续补匹配认账。
- 右上角系统版本号更新为 `v10.08`。
- 部署包：`releases/finance-platform-v10.08-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 打包明细上传

- `认账及分账` 上传订单明细时，打包明细规则不再手工指定到账日期。
- 系统按明细认账规则中的匹配到账信息，自动查找符合条件的最早未完成认账银行流水。
- 查找范围包含未认账流水，以及仍有剩余可认账金额的部分认账流水。
- 若上传时未找到对应银行流水，订单明细包仅在 `订单明细包` 菜单展示，匹配日期显示 `-`，不生成日期汇总任务。

## 订单明细包

- 未匹配流水的打包明细包新增 `待匹配流水` 状态。
- `订单明细包` 列表新增“匹配流水认账”操作，可在后续上传对应银行流水后手动补匹配并提交认账队列。
- 单文件和按日期/规则范围查看明细均兼容匹配日期为 `-` 的打包明细包。

## 实例修复

- 修复 `钱袋宝-城市森林明细` 这类场景：目标流水 `801594869474` 已被其他订单包部分认账时，系统仍可按剩余可认账金额匹配后续订单明细包。
- 查找部分认账流水时会计算 `银行流水收入金额 - 已认账金额`，余额大于 `0.01` 才允许作为候选流水。

## 数据库迁移

- 本版无新增数据库迁移。
