# v10.49-local 版本快照

## 发布范围

- 修复未匹配银行到账的多日汇总订单明细包删除失败：占位匹配日期不再作为 MySQL 日期查询认账任务，已匹配多日包和 T+1 包仍按真实日期回算。
- 银行到账新增中国银行格式，广发银行、工商银行和中国银行统一按表头识别；旧版 `.xls` 不再固定按广发银行解析。
- 中国银行按双语表头映射流水字段，只接收 `交易金额[ Trade Amount ]` 为正数的行；前端解析与服务端入库均执行正数保护。
- 中国银行到账账号通过“财务凭证信息 / 银行/到账账号”手工维护并支持设置默认账号，文件顶部查询账号不自动采集。
- 凭证模板变量新增 `【银行】`、`【季度】`，删除 `【利息信息】`；历史模板中的旧变量在页面读取和服务端渲染时自动清空，不直接改写数据库。
- 利息逐笔制单的输入改为可选“摘要内容”：未填写时完整使用利息模板，填写后只覆盖摘要，科目编码、科目名称、借方金额和贷方金额继续使用模板。
- 利息批量制单不再因缺少人工信息跳过，直接使用利息模板生成；制单弹窗未输入摘要内容时显示“自动内容”，输入后显示实际内容。
- 操作指引更新为银行到账自动认账、订单明细认账、明细分账、T+1 异常处理和打包订单明细异常处理五个章节。
- 右上角系统版本号更新为 `v10.49`。
- 部署包：`releases/finance-platform-v10.49-local.tar.gz`，包含本地验证通过的预构建 `dist/`，服务器不再执行 Vite/esbuild 构建。

## 数据库、依赖与配置

- 本快照只记录从 v10.48 升级到 v10.49 的变化。
- 本版本不新增数据库表、字段、索引或迁移脚本，不执行 `drizzle schema push`。
- 本版本不新增 npm 依赖，不调整运行配置。
- v10.48 的月归档索引灰度和正式清理不是本版迁移，继续按 `docs/DEPLOY_v10.48-local.md` 的数据库状态与观察窗口独立执行。
- 凭证模板仍保存于 `voucher_template_settings.templates` JSON；旧 `【利息信息】` 只在读取和渲染时清理，用户保存模板后才会把清理结果写回数据库。

## 风险与回退

- 中国银行表头必须包含约定的双语字段；缺少关键表头时停止上传，避免按错误银行格式入库。
- 中国银行付款人账号、名称或开户行为空时仍允许正数流水入库；本方账号需提前手工维护默认账号，否则流水允许保持空关联。
- 历史利息模板如包含 `【利息信息】`，新版会将该占位符清空；上线后应检查利息模板摘要是否仍为完整可用文案，并按需改用 `【银行】`、`【季度】`等变量。
- 自定义摘要内容仅覆盖利息凭证摘要，其他模板字段和其他收入类型不受影响；已生成凭证继续读取历史快照，不自动重算。
- 未匹配多日订单包删除仍受锁定结果、归档状态和分账绑定等原有保护约束，本版只修复占位日期查询错误。
- 代码可使用 `releases/finance-platform-v10.48-local.tar.gz` 回退；本版没有数据库结构变化，无需数据库回滚。
- 部署脚本使用本轮固定 `dist` 备份原子切换；暂存校验、启动或 HTTP 健康检查失败时恢复本轮部署前产物。
