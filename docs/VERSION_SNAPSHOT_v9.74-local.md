# v9.74-local 版本快照

## 发布范围

- 本版用于替代 v9.73-local 包，包含账号角色与权限入口调整。
- 部署包：`releases/finance-platform-v9.74-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 账号角色

- 账号管理新增 `财务人员` 角色。
- 账号列表、创建账号弹窗和顶部当前用户角色标签均支持显示财务人员。
- 后端用户创建/更新校验和数据库用户角色枚举同步支持 `finance`。

## 权限入口

- 运营人员和财务人员在左侧不显示“账号管理”菜单；账号管理路由继续仅管理员可访问。
- 运营人员和财务人员在“认账及分账”日期汇总列表不显示删除入口。
- 运营人员和财务人员在“明细分账”上传批次列表不显示删除入口。
- 相关删除接口增加管理员校验，避免绕过页面直接调用。
- 日期汇总详情的银行流水列表不再显示“取消认账”入口。
- 入账结果菜单中，运营人员不显示单条“制单 / 取消制单”和“批量制单”按钮；后端同步限制运营人员调用制单接口。

## 数据库迁移

- 本版新增迁移：`migrate-v9.74-finance-role.sql`。
- 线上部署 v9.74 前必须执行该迁移，将 `users.role` 枚举扩展为 `admin / operator / finance`。
- 如果目标环境尚未部署 v9.70，还需要先执行 `migrate-v9.70-detail-split-rule-upload-fields.sql`。

## 验证

- `npm run check` 通过。
- `npm run build` 通过。
- 发布包完整性检查通过，沿用历史轻量发布方式，不包含本地 `dist`，由服务器部署脚本重新构建。
- 发布包未包含 `node_modules`、`.upload-cache`、`releases` 等本地大目录。
