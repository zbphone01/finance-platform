# v9.54-local 版本快照

## 打包明细上传

- 上传订单明细时，如果所选明细认账规则对应的明细包类型为 `打包明细`，弹窗会显示并要求选择 `到账日期`。
- 打包明细订单包按用户选择的到账日期生成，并在该日期匹配同日打包到账的银行流水进行认账。
- 分片上传创建会话和完成上传两个阶段都会携带 `matchDate`，服务端在开始处理前写入上传会话，避免断点续传或会话复用时丢失匹配日期。
- 打包明细缺少有效到账日期时不再默认使用上传当天，而是直接提示 `请选择有效的到账日期`。
- 失败的订单明细上传会话不再复用，避免旧的无效上传会话污染后续重试。

## 订单明细包

- `订单明细包` 页面搜索占位文案改为 `搜索订单日期/匹配日期、规则、文件或上传账号`。
- `订单明细包` 页面与日期汇总任务详情中的列头由 `订单日期/上传日期` 改为 `订单日期/匹配日期`，与打包明细按到账日期匹配的业务语义一致。

## 数据库迁移

- 本版无新增数据库迁移。
- 复用现有 `order_files.upload_date` 保存打包明细的匹配日期；真实上传时间继续使用 `created_at`。

## 发布说明

- 本版暂不进行线上部署。
- 本版部署包仅用于记录和留档，计划随下一版一起部署到线上。
