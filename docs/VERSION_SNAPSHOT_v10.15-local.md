# v10.15-local 版本快照

## 发布范围

- 本版调整财务凭证信息菜单结构，新增收入渠道管理页面，并将到账信息中的凭证收款渠道改为基础数据下拉选择。
- 制单生成的凭证行会保存静态行类型和浮层 JSON，凭证详情读取已保存快照，避免后续基础资料改名影响已制单凭证。
- 右上角系统版本号更新为 `v10.15`。
- 部署包：`releases/finance-platform-v10.15-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 财务凭证信息

- `财务凭证信息` 改为一级菜单，包含 `凭证模板` 和 `收入渠道管理` 两个二级菜单。
- `凭证模板` 承接原财务凭证信息模板维护能力。
- `收入渠道管理` 承接凭证收款渠道基础数据维护，支持新增、编辑、删除和按 `n.n` 编号数值顺序排序。
- 收入渠道管理顶部展示渠道条数统计，新增和编辑使用弹窗操作。

## 到账信息与制单

- 到账信息中的 `凭证收入名称` 改名为 `凭证收款渠道`。
- 编辑到账信息时，凭证收款渠道改为下拉选择，选项来自收入渠道管理，保存渠道编号 `channelCode`。
- 制单模板变量 `【凭证收入名称】` 更名为 `【凭证收款渠道名称】`，本版不兼容旧变量。
- 制单摘要使用渠道名称，凭证详情项目资金和管理费行浮层展示 `编号_名称`。
- 制单结果行新增 `line_type` 和 `explanation_json`，用于保存项目资金行、管理费行的浮层快照。

## 数据库迁移

- 从 v10.14 升级到 v10.15 需要执行：
  - `migrate-v10.15-voucher-line-explanation-json.sql`
- 该脚本为 `voucher_result_lines` 新增 `line_type` 和 `explanation_json` 字段。
- 如果目标环境尚未部署 v10.14，需要先执行 `migrate-v10.14-voucher-receipt-channels.sql`，再执行 v10.15 迁移。
