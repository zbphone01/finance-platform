# v9.39.0-local 版本快照

## 认账及分账性能优化

- 修复进入 `查看日期汇总` 后银行流水列表仍卡顿的问题：
  - 日期汇总详情页改为只挂载当前页签，避免默认打开银行流水时同步加载入账结果列表。
  - 手动认账所需的部门、预算编码、项目、公益平台、捐赠活动树改为选中未认账流水后才加载，避免只查看流水列表时拉取大字典。
- 优化树形字典接口：
  - 部门、预算编码、项目、捐赠活动由反复全量过滤改为按父级分组后组装。
  - 公益平台树由平台/项目/详情反复过滤改为 Map 分组组装。
- 新增数据库索引：
  - `recognition_date_summaries(status, bill_date)`：加速日期汇总按状态筛选和日期排序。
  - `bank_flows(task_id, id)`：加速银行流水按日期汇总任务集合分页读取。

## 数据库

- 新增迁移脚本：`migrate-v9.39-recognition-list-performance.sql`。
- 本地和线上部署前均需执行该迁移，索引已存在时无需重复创建。
