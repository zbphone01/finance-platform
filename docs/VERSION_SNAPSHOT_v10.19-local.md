# v10.19-local 版本快照

## 发布范围

- 本版完成凭证详情汇总行浮层、到账认账分账字段、明细认账固定收入口径和入账结果列表字段调整。
- 右上角系统版本号更新为 `v10.19`。
- 部署包：`releases/finance-platform-v10.19-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 凭证详情

- 凭证详情第一行汇总行新增说明浮层，样式沿用项目资金行和管理费行。
- 汇总行浮层字段为 `结算方式`、`银行账户`，当前值暂按 `-` 写入。
- 制单时汇总行浮层内容会一并生成并保存到 `voucher_result_lines.explanation_json`，详情页读取制单快照。

## 到账认账规则

- 到账认账规则分账设置在 `收入类型` 后新增 `捐赠来源`。
- `收入类型 = 捐赠收入` 时，捐赠来源必填，选项为 `互联网募捐平台`、`银行直捐`、`拍卖`。
- 到账认账规则编辑页去掉顶部 `认账类型` 切换，新建、复制和保存继续默认写入历史兼容值 `渠道捐赠`。
- 分账必填字段改为按捐赠来源或收入类型判断：
  - `互联网募捐平台`：收入属性、收入部门、预算编码、NC项目名称、平台项目名称、平台项目详情、支出资金来源、管理费。
  - `银行直捐`、`拍卖`、非捐赠收入默认模式：收入属性、收入部门、预算编码、NC项目名称、支出资金来源、反馈类型、地区、管理费。
  - `会费收入`：收入属性、收入部门、预算编码、NC项目名称、反馈类型、支出资金来源、地区、匿名、会员姓名，管理费按空/0 处理。
  - `政府补助`、`利息`、`个税返还`、`本金`、`投资收益`：收入属性、收入部门、预算编码、NC项目名称，管理费按空/0 处理。
  - `其他收入`、`其他`：收入属性，可填写备注，管理费按空/0 处理。
- 收入类型 `个税返还本金` 拆分为 `个税返还` 和 `本金`，历史旧值通过迁移回填为 `个税返还`。

## 明细认账与入账结果

- 明细认账规则分账设置去掉 `收入类型` 选择，保存时固定为 `捐赠收入`。
- 明细认账规则分账设置新增固定展示字段 `捐赠来源 = 互联网募捐平台`。
- 所有普通订单明细认账入账结果的捐赠来源统一写入 `互联网募捐平台`；退款订单捐赠来源为空；地区继续根据到账信息写入认账结果。
- 明细认账不需要填写反馈类型、会员姓名、匿名和备注，生成入账结果时不额外计算这些字段。
- 入账结果菜单去掉 `认账类型` 字段和列，入账明细列表表头调整为：入账时间、流水号、收入类型、捐赠来源、收入属性、收入部门、预算编码、NC项目名称、平台项目名称、平台项目详情、反馈类型、地区、会员姓名、匿名、订单明细数、备注、入账金额、项目资金、管理费、状态。
- 入账结果的 `备注` 用于承载到账认账规则分账备注快照；明细认账结果无备注时显示 `-`。
