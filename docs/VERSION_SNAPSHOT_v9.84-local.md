# v9.84-local 版本快照

## 发布范围

- 本版用于替代 v9.83-local 包，包含账号密码管理增强，以及整包入账打包明细多规则共用同一银行到账的回归修复。
- 部署包：`releases/finance-platform-v9.84-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 账号与密码

- 左下角当前用户区域新增修改密码入口。
- 修改密码时需输入原密码，新密码至少 6 位。
- `账号管理` 列表操作区新增编辑入口。
- 管理员可编辑单个账号的角色和启用状态。
- 管理员可重置单个账号密码，系统会生成随机 6 位英文数字混合密码，并在弹窗中提示和支持复制。
- 防止管理员停用当前登录账号或修改当前登录账号角色，避免误操作导致自己失去权限。

## 整包入账打包明细

- 修复 v9.72 后流水状态同步覆盖 v9.63 整包汇总判断的问题。
- 关闭条件认账的打包明细继续按 v9.63 约束执行：同到账别称、同匹配日期、所有有效打包明细包共同参与整包判断。
- 同一银行到账对应多个整包规则时，执行认账会为剩余已匹配但未入账的整包规则补生成入账结果。
- 流水状态同步遇到整包场景时，按银行到账总额、打包明细包净额合计、已生成入账结果合计三者一致来判断已认账，不再只看当前任务单规则结果。
