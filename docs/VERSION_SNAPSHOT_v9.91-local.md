# v9.91-local 版本快照

## 发布范围

- 本版用于修复订单明细包和明细分账包删除链路、订单明细分片上传状态读取问题，并优化认账详情展示。
- 右上角系统版本号更新为 `v9.91`。
- 部署包：`releases/finance-platform-v9.91-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 订单明细包删除

- 单文件订单明细包删除改为复用多文件删除弹窗；只有一个来源文件时，仅展示“删除整个数据包”选项。
- 删除弹窗在删除过程中保持打开，并显示步骤提示：
  - `1/4 正在回滚明细分账认账状态`
  - `2/4 正在删除入账结果`
  - `3/4 正在删除订单明细包`
  - `4/4 正在重置银行流水认账状态`
- 删除完成后自动刷新列表并关闭弹窗，减少重复点击删除导致的误操作。
- 后端删除逻辑改为只处理本次数据包实际关联的入账结果，不再按整个任务粗范围删除。
- 已拆分的订单明细包删除时，会释放对应明细分账条目的绑定，后续重新上传订单明细包后可继续复用原明细分账包执行拆分认账。

## 明细分账包删除

- 明细分账包删除改为按实际关联入账结果精确回滚，先恢复来源订单明细待拆分状态，再删除入账结果和分账明细。
- 删除核心写操作放入事务，降低第一次删除报错、第二次才完成的半删除风险。
- 已制单或锁定的入账结果仍会阻止删除，避免误删已锁定业务结果。

## 订单明细上传

- 订单明细分片上传的状态文件改为临时文件写入后原子替换，读取状态时遇到半截 JSON 会短暂重试。
- 修复上传弹窗偶发提示 `Unexpected end of JSON input` 的问题。
- 明细分账上传使用同样的状态文件读写保护，避免同类问题。
- 调整订单明细上传进度分段，使文件上传、合并和服务器处理阶段的进度更贴近真实处理过程。

## 认账详情与提示

- 任务详情顶部金额展示补充 `¥`，并将指标名称调整为“银行流水到账总额”“订单明细认账金额”。
- 任务详情的已认账数量改为展示已认账银行流水数 / 流水条数。
- 差异大任务下，银行流水列表继续展示认账差异列，并区分差异状态下的部分认账和未认账流水。
- 订单明细状态筛选下拉框加宽，避免长状态名称显示拥挤。
- 明细认账说明文案统一为“订单明细利用规则中的匹配到账信息查找认账用银行流水，并按设置进行认账”。
- 登录失败改为返回标准未授权错误，前端和接口调用方能更稳定识别认证失败。
