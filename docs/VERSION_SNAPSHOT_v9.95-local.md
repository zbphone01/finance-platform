# v9.95-local 版本快照

## 发布范围

- 本版用于补齐认账及分账列表的批量制单入口，并调整日期汇总银行流水分页数量。
- 右上角系统版本号更新为 `v9.95`。
- 部署包：`releases/finance-platform-v9.95-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 认账及分账

- 日期汇总列表操作列中的制单 icon 改为可点击。
- 点击制单 icon 后，会对当日已认账、未制单的银行流水批量生成凭证。
- 批量制单复用单笔制单逻辑；同日汇总场景会保持一张凭证关联多笔银行流水。
- 单次批量制单保护上限为 500 条待制单银行流水；超过上限会提示拆分处理或改后台队列。
- 批量制单完成后刷新日期汇总、银行流水、凭证汇总和入账结果统计。
- 日期汇总详情中的银行流水列表分页从每页 20 条调整为每页 40 条。

## 数据库迁移

- 本版没有新增数据库迁移。
- 已部署 v9.94 的环境可直接部署 v9.95 代码。
- 如果目标环境尚未部署 v9.94，需要先执行 `migrate-v9.94-voucher-template-settings.sql`，再部署 v9.95。
