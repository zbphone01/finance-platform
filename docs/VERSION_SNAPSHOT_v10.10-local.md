# v10.10-local 版本快照

## 发布范围

- 本版用于优化认账及分账日期汇总状态一致性、明细分账自动认账后的刷新时效，并精简日期汇总订单明细列表交互。
- 右上角系统版本号更新为 `v10.10`。
- 部署包：`releases/finance-platform-v10.10-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 认账及分账

- 日期汇总列表中的 `差异大` 状态仅保留状态展示，不再支持点击打开差异提示弹窗。
- 日期汇总详情顶部状态改为先刷新并读取同一份 `recognition_date_summaries` 汇总，和认账及分账列表状态保持同源。
- 认账状态文案、颜色和图标抽到公共前端配置，日期汇总列表和详情页共用同一套展示口径。
- 日期汇总订单明细列表去掉 `搜索订单金额` 输入框，保留状态筛选和分页。

## 明细分账

- 明细分账包上传入库完成后，提示进入拆分认账阶段，避免把上传完成误解为认账完成。
- 自动拆分认账启动和结束后，前端会主动刷新明细分账列表、订单明细包列表和日期汇总列表。
- 认账队列完成后会先刷新关联明细分账包快照，再刷新日期汇总，减少列表状态和计数延迟。
- 日期汇总详情在后台认账执行中自动轮询任务汇总和订单明细列表；任务结束后额外复查，减少详情页汇总延迟。

## 数据库迁移

- 本版无新增数据库迁移。
- 从 v10.09 升级到 v10.10 可直接部署代码包。
- 如目标环境尚未部署 v10.09，需要先按 v10.09 文档补齐 v10.00、v10.01、v10.02 迁移。
