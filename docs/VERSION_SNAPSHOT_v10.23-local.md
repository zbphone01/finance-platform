# v10.23-local 版本快照

## 发布范围

- 本版聚焦预算编码筛选、会费收入认账默认项、凭证浮层展示、凭证模板文案和操作指引页面。
- 右上角系统版本号更新为 `v10.23`。
- 部署包：`releases/finance-platform-v10.23-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 预算编码

- 预算编码一级部门支持维护关联收入部门；编辑部门后，关联部门在到账认账规则、手动认账选择预算编码时一并参与筛选。
- 渠道预算编码的编号改为非必填；新增渠道未填写编号时，渠道预算编码继承所属 NC 项目的 `n.n` 编号。
- 同一 NC 项目下若已存在继承编号的渠道，则不允许继续新增渠道，避免与 NC 项目编号混淆。

## 会费收入认账

- 到账认账规则和手动认账选择 `会费收入` 时，不再要求填写支出资金来源。
- 会费收入的捐赠活动默认按 `101_日常捐赠` 用于凭证展示。
- 会费收入的支出资金来源默认 `非限定性_企业家捐赠`。
- 当预算编码为 `2.1-其他银行直捐` 时，支出资金来源默认 `非限定性-项目中心-企业家捐赠`。
- 手动认账会费收入新增缴纳年限，供凭证模板变量 `【缴纳年限】` 使用。

## 凭证与模板

- 凭证项目费用行浮层去掉 `结算方式`。
- 凭证浮层的 `收款活动类型` 改为显示 `编号_活动说明`；会费收入默认 `101_日常捐赠`。
- 凭证浮层中的 `客户` 改为取到账户名，并在制单时写入凭证行解释快照。
- 凭证浮层宽度改为按内容自适应，长内容自动换行，减少横向滚动。
- 凭证模板菜单中 `变量解释` 改为 `模板变量说明`，变量列表去掉 `【凭证收款渠道】`。
- 编辑到账信息中 `凭证收款渠道` 的说明文案改为 `用于制单时的收款渠道`。

## 操作指引

- 左侧菜单新增 `操作指引`，位置在 `账号管理` 上方。
- 操作指引页面新增银行到账设置自动认账、订单明细认账两类说明。

## 数据库迁移

- 本版包含两个新增迁移：
  - `migrate-v10.21-membership-payment-years.sql`
  - `migrate-v10.22-budget-code-associated-departments.sql`
- `migrate-v10.21-membership-payment-years.sql` 为 `match_results` 新增 `membership_payment_years` 字段。
- `migrate-v10.22-budget-code-associated-departments.sql` 为 `budget_codes` 新增 `associated_departments` 字段。
- 本地数据库已确认两个字段均存在。
- 如果目标环境尚未部署 v10.20，需要先按 v10.20 文档补齐历史迁移。
