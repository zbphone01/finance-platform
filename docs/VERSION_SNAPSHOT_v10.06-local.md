# v10.06-local 版本快照

## 发布范围

- 本版用于优化大订单明细上传稳定性、认账及分账开始认账反馈，以及订单明细手动认账页展示。
- 右上角系统版本号更新为 `v10.06`。
- 部署包：`releases/finance-platform-v10.06-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 订单明细上传

- 订单明细上传服务端分批入库从每 10000 行降回每 5000 行，降低大订单明细在低内存测试服务器上触发调用栈溢出或大 SQL 构造失败的风险。
- 上传订单明细弹窗提示文案同步更新为每 5000 行分批入库。

## 认账及分账

- 点击“开始认账”后，不再使用浏览器确认框，改为弹窗显示 `n/4` 步骤文案，覆盖任务检查、可执行判断、提交认账和刷新状态。
- 开始认账完成后，在弹窗内展示到账认账任务数、匹配流水数、明细认账入队数和跳过任务数；点击确认后刷新列表状态。

## 订单明细手动认账

- 手动认账页顶部改为展示完整订单明细内容，按订单文件原始列横向表格展示。
- 匹配的银行流水号与订单明细表格合并为同一内容模块，并优化间距、字号和金额列右对齐。

## 数据库迁移

- 本版无新增数据库迁移。
- 如目标环境尚未部署 v10.05，需要先按 v10.05 文档补齐 v10.00、v10.01、v10.02 迁移。
