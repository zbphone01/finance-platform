# v10.07-local 版本快照

## 发布范围

- 本版用于优化手动开始认账调度、明细认账队列状态回写、明细分账上传后自动拆分认账，以及补充测试业务数据清空规则说明。
- 右上角系统版本号更新为 `v10.07`。
- 部署包：`releases/finance-platform-v10.07-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 认账及分账

- 手动点击“开始认账”时，先按当天银行流水状态筛选候选任务，跳过已完成、处理中和无流水任务。
- 未认账流水继续同步执行到账认账；部分认账和差异大任务在确认有订单明细后直接进入明细认账队列。
- 开始认账弹窗步骤文案调整为：筛选待认账流水、处理到账认账、提交明细认账队列、刷新认账状态。
- 开始认账完成弹窗仅展示分项统计，避免总句和到账认账、明细认账、跳过统计重复展示。
- 明细认账后台队列在任务成功或失败后都会兜底刷新日期汇总缓存，避免日期汇总停留在“认账执行中”。
- 认账及分账列表在存在执行中任务时，轮询间隔从 15 秒缩短到 5 秒。

## 明细分账

- 明细分账包上传成功后自动执行一次拆分认账，页面提示改为“上传并执行”。
- 自动拆分认账时，如果暂无可拆分认账的订单明细包，不再把上传结果回退为失败；手动点击开始拆分认账仍保留原错误提示。

## 协作与排错说明

- `docs/finance-recon-SKILL.md` 新增清空本地/测试服务器业务测试数据的标准范围、保留范围和复查要求。

## 数据库迁移

- 本版无新增数据库迁移。
- 如目标环境尚未部署 v10.06，需要先按 v10.06 文档补齐 v10.00、v10.01、v10.02 迁移。
