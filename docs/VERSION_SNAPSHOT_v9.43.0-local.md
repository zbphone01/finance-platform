# v9.43.0-local 版本快照

## 认账信息设置提速

- 公益平台设置页首屏只加载平台列表，展开公益平台后再加载平台项目名称，展开项目后再加载项目详情。
- 预算编码设置页首屏只加载根级部门，展开部门和 NC 项目时逐级加载下级。
- 公益平台和预算编码设置页搜索改为后端搜索，直接返回命中节点和路径，避免打开页面与输入搜索时加载、过滤整棵树。
- 原完整树接口保留给规则和手动认账选择器使用，不改变既有表单联动口径。

## 部分认账续认

- 日期详情银行流水中的 `部分认账` 状态可点击，继续进入手动认账表单。
- 部分认账表单增加本次认账金额和可认账金额展示。
- 可认账金额按该流水收入减去已生成入账结果金额计算；前后端均限制本次认账金额大于 0 且不超过可认账金额。
- 部分金额认账后新增入账结果并扣减可认账金额；剩余金额未补齐时继续显示部分认账，补齐后切为已认账。

## 部署影响

- 本版本没有新增数据库迁移。
- `package.json` 和锁文件未新增依赖；按现有优化部署脚本部署即可。
