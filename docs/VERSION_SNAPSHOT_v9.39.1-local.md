# v9.39.1-local 版本快照

## 页面显示优化

- 到账信息汇总：
  - 已记录列表的 `到账别称` 列改为按内容自动宽度展示，不再截断长别称。
  - 已记录列表的 `操作` 列固定在右侧，横向滚动时编辑、删除按钮保持可见。
- 入账结果：
  - 入账明细列表右侧 `入账金额 / 状态 / 操作` 三列固定显示。
  - 固定列增加白色背景、固定宽度和遮罩阴影，避免滚动内容从固定列下方透出。

## 公益平台

- 在公益平台子菜单新增平台项目名称时，如果所选 NC项目名称下已有平台项目名称，保存前提示：

```text
该NC项目有平台项目【平台项目名称】，是否继续添加？
```

- 用户确认后继续创建，取消则不保存。

## 数据库

- 本版本无数据库迁移。
- 仍需确保线上已执行 v9.39 的索引迁移。

## 验证

- `npm run check` 通过。
- `npm run build` 通过。
