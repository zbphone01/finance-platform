# v9.59-local 版本快照

## 发布范围

- 本版用于替代 v9.58-local 包，包含明细分账包上传、订单明细大文件上传性能优化，以及订单明细包删除交互修正。
- 部署包：`releases/finance-platform-v9.59-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 明细分账包

- 新增一级菜单 `明细分账包`，列表表头为：上传日期、匹配订单明细包 id、条目数、上传信息、状态、操作。
- `认账及分账` 页面新增 `上传明细分账` 按钮，位于 `上传订单明细` 左侧。
- 明细分账上传先选择开启明细分账且存在待拆分明细的订单明细包，再填写明细匹配字段、收入字段，并上传 CSV / XLSX 文件。
- 明细分账包采用分片上传和后台处理；文件缺少明细匹配字段或收入字段时直接失败并丢弃。
- 明细分账预匹配按明细匹配字段汇总收入，和来源订单明细包的待拆分明细金额一致且能匹配认账条件时，分账明细入库为已匹配，并把来源订单明细标记为已拆分。
- 已匹配的分账明细入库后会触发明细认账队列，用分账明细金额进行认账。

## 订单明细上传

- CSV 订单明细解析改为边读边处理，不再先把完整 CSV 文件读入内存。
- CSV 流式解析保留 UTF-8 / GB18030 编码识别，并使用流式 `TextDecoder` 处理跨块中文字符，避免中文乱码。
- 订单明细批量入库批次从 2000 行提高到 5000 行，减少大文件数据库往返次数。
- 上传开始阶段按明细认账规则配置字段做精确列头校验，不再对规则字段做别名兼容；缺列时直接取消上传。
- 表头校验通过后记录规则字段到文件列头的映射，逐行处理时直接按映射取值。
- 单行缺少订单号、日期或收入金额时跳过该行，不再导致整个文件失败；上传成功提示显示跳过条数。
- `bill_details.rawData` 只保存规则实际需要的核心字段，降低大批量 JSON 写入成本。

## 订单明细包

- 修复失败上传且没有明细的空订单明细包无法删除的问题。
- 删除大订单明细包时，切换菜单再返回仍会显示删除中并禁用删除按钮，避免重复触发删除。

## 数据库迁移

- `migrate-v9.59-detail-split-files.sql`
  - 新增 `detail_split_files` 表，用于记录明细分账包。
  - `bill_details` 新增 `detail_split_file_id`、`split_source_detail_id`，用于关联分账包和来源待拆分明细。

## 延续约束

- 订单明细包和认账及分账列表首屏继续读取缓存字段，不得改回实时扫描大明细表。
- 明细认账规则列表的普通 `编辑` 入口必须保持整体编辑；单条件编辑只保留在规则详情页。
- CSV 大文件上传需要保持分片合并后再解析，解析阶段必须继续使用流式解码，避免中文跨块乱码。
