# v9.90-local 版本快照

## 发布范围

- 本版用于修复支付宝 T+1 同日汇总明细认账的多笔银行到账状态展示和重新认账问题。
- 右上角系统版本号更新为 `v9.90`。
- 部署包：`releases/finance-platform-v9.90-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 同日汇总明细认账

- 保留现有同日汇总认账逻辑，不改成每组订单逐笔吃银行到账金额。
- 同日多笔银行到账的已认账状态改为按同日同规则的累计认账金额判断：
  - 已被累计金额完整覆盖的银行到账显示为已认账。
  - 当前被累计金额部分覆盖的银行到账显示为部分认账。
  - 尚未覆盖的银行到账显示为未认账。
- 手动重新认账时，若历史同日汇总结果已经过期，会先清理旧的明细认账结果，再重新执行认账，避免任务被旧状态跳过。
- 无银行流水的 T+1 明细认账任务保持待认账，不再误判为差异大。

## 日期汇总

- 同日汇总匹配下，多笔银行到账共用同一订单明细差额时，日期汇总顶部的订单异常金额按同日同规则去重展示，避免 1 元差额被多笔银行到账重复累计。

## 明细认账规则编辑

- 保留前一版条件卡片和属性下拉减少重复渲染的优化。
- 在此基础上继续降低条件输入时的连带刷新，减少编辑明细认账规则时的卡顿感。
