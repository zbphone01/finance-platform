# v9.61-local 版本快照

## 发布范围

- 本版用于替代 v9.60-local 包，包含订单明细认账基础规则修正、同日汇总流水状态修复、上传取消交互、明细分账组合关键字预匹配和相关维护约束。
- 部署包：`releases/finance-platform-v9.61-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 订单明细认账

- 订单明细认账统一增加前置规则：只有匹配到账总额或剩余可认账金额大于等于未转移、未忽略的订单明细总金额时，才开始明细认账；否则只计算差异金额并提醒。
- 因为有前置金额校验，执行阶段不再用单条明细金额逐条试探到账余额，而是按明细认账规则条件汇总入账。
- 同日汇总会先找到同日、同规则、同到账信息匹配条件的所有流水，再按流水顺序消耗可认账金额。
- 删除订单明细包时，会回滚同日同规则相关流水任务的入账结果，并按剩余入账结果金额重新计算流水认账状态。
- 明细金额判断只允许明确 `0.00` 不生成入账结果；`0.01` 等小额正数必须正常入账，负数退款明细保留生成入账结果路径。

## 上传交互

- 订单明细上传和明细分账上传在上传中提供 `取消上传`。
- 取消上传只要求前端立即终止当前网络请求和状态轮询；后端已开始或已排队的处理按原流程自然完成，不做强制中断或回滚。
- 上传订单明细弹窗提示中的服务端批量入库行数修正为每 `5000` 行。

## 明细分账预匹配

- 明细分账待拆分预匹配改为使用“条件认账关键字 + 明细分账判断关键字”的组合关键字。
- 只有当明细分账判断字段与条件的认账关键字字段一致时，才参与组合。
- 组合关键字空格会归一化，匹配方式沿用条件自身的 `等于 / 包含`。
- 预匹配顺序固定为：`等于 -> 组合等于 -> 组合包含 -> 普通包含`。
- 不再恢复为仅按配置字段末尾关键字 `endsWith` 的全局快路径。
