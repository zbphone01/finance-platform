# v9.41.0-local 版本快照

## 到账认账规则

- 到账认账规则新增查看和复制入口，查看页按规则详情展示基本信息与分账设置。
- 新建与复制到账认账规则支持选择 `到账认账` 到账别称或 `自定义` 匹配到账信息。
- 选择到账别称时自动回填并锁定对方户名、用途、附言；同一到账别称已有到账认账规则时阻止创建并保留当前填写内容。
- 到账信息改名、用途或附言更新时同步已引用的到账认账规则；已被到账认账规则使用的到账信息不允许改成明细认账。

## 明细认账规则

- 修复保存后立即再次进入编辑时条件偶发不回显的问题。
- 编辑规则页切回窗口后刷新项目树和公益平台树，可选到新绑定的 NC项目、平台项目名称和项目详情。
- 匹配到账信息下拉显示明细包类型；规则列表和上传订单明细选规则时同步显示 `规则名（T+1）` 或 `规则名（打包明细）`。
- 新增但未保存的条件标题显示 `条件 N（未保存）`。

## 认账信息设置

- 预算编码编辑关联 NC项目时前后端均阻止重复关联并提示检查。
- 关联 NC项目超过 15 个时列表改为滚动，不再撑高编辑弹窗。
- 预算编码列表搜索区参考公益平台列表固定在顶部。
- 公益平台新增平台项目名称时，已有同 NC项目平台项目提示只在当前公益平台范围内判断。

## 登录页

- 登录页等待会话检查或账号验证时展示进度，减少登录页打开和提交阶段的无反馈等待。

## 数据库

- 新增迁移脚本 `migrate-v9.41-income-rule-counterparty-alias.sql`。
- 迁移为 `income_recognition_rules` 新增 `matched_counterparty_alias`，用于保存到账认账规则选择的到账别称。
