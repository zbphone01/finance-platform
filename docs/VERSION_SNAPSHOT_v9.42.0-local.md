# v9.42.0-local 版本快照

## 订单明细上传

- 订单明细文件新增 `.xlsx` 支持，保留 `.csv` 上传。
- CSV 继续走流式解析；XLSX 复用分片上传与每 2000 行分批入库，解析阶段读取 Excel 工作簿行。
- 易宝订单明细样例兼容 `下单时间`、`商品信息` 列名。

## 入账结果

- 当天入账明细列表每页从 20 条调整为 15 条。
- 按天汇总新增“批量制单”，可将当天待制单入账明细一次标记为已制单。
- 批量制单接口按入账日期与待制单状态直接更新，不先加载当天全部明细 ID。

## 认账信息设置

- 到账信息汇总“未记录”数量改为读取统计接口，新增银行到账后立即刷新，不再依赖先打开未记录页签。
- 公益平台最后一行“添加平台项目名称”入口与上方展开箭头左边界对齐。

## 部署影响

- 新增订单明细 XLSX 解析依赖，`package-lock.json` 有变化，线上部署时需要安装新依赖。
- 本版本没有新增数据库迁移；若线上尚未部署 v9.41，仍需先执行 `migrate-v9.41-income-rule-counterparty-alias.sql`。

## 验证

- `npm run check` 通过。
- `npm run lint` 通过。
- `npm run build` 通过。
- `npm test -- api/lib/orderUploadStream.test.ts` 通过。
