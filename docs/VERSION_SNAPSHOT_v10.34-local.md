# v10.34-local 版本快照

## 发布范围

- 本版调整“认账及分账 -> 日期汇总 -> 订单明细”的忽略与转入展示口径。
- 右上角系统版本号更新为 `v10.34`。
- 部署包：`releases/finance-platform-v10.34-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 日期汇总订单明细口径

- 已忽略订单不再出现在日期汇总订单明细列表，只在独立“已忽略订单”列表中管理。
- 状态筛选移除原“已忽略”和“已转移”选项。
- T+1 订单转移后按目标 `partition_date` 进入目标日期明细，不再因原始订单日期不是目标日前一天而被过滤。
- 未认账筛选继续包含转入后尚未认账的订单，与日期汇总数字保持一致。

## 转入本日筛选

- 状态下拉新增“转入本日”，按 `operation_status = 'transferred'` 筛选当前目标日期分区的 T+1 订单。
- 筛选结果同时包含已认账和未认账的转入订单。
- 第一列“订单日期/匹配日期”继续显示原始订单日期，转移不修改 `bill_date`。
- 已转移状态展示、取消转移和数据追溯机制保持不变。

## 数据库与依赖

- 本版不新增数据库迁移；已部署 v10.33 或 v10.32 的环境可直接部署 v10.34 代码包。
- 从 v10.31 或更旧版本升级时，先按历史部署说明补齐至 v10.32。
- 本版不新增依赖，不需要安装新包，不执行 `drizzle schema push`。
