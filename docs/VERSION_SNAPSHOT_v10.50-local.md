# v10.50-local 版本快照

## 发布范围

- 中国银行流水摘要优先读取 `备注[ Remarks ]`；备注为空或只有空格时，回退读取 `业务类型[ Business type ]`。
- 左侧导航在低分辨率或一级菜单全部展开时，仅菜单列表区域竖向滚动；顶部平台标题和底部用户操作区固定，滚动条隐藏但保留鼠标滚轮、触控板和触屏滚动。
- 利息逐笔制单弹窗未填写“摘要内容”时，不再显示固定“自动内容”，改为使用正式制单同一套模板和变量生成实际摘要预览；填写后仍实时显示输入内容。
- 凭证模板变量说明更新 `【到账户名】`、`【银行】`、`【到账月份】`、`【季度】` 的银行流水口径。
- “银行/到账账号”菜单将页面字段“账号别称”更名为“凭证名称”；数据库字段和接口字段继续使用 `account_alias` / `accountAlias`，已有数据和制单取值不变。
- 入账明细中，会费收入、政府补助、个税返还、本金、投资收益、利息、其他收入和其他的项目资金、管理费统一显示 `-`；捐赠收入和订单退款继续显示金额。该调整只影响明细展示，不改变数据库保存值和入账汇总统计。
- 右上角系统版本号更新为 `v10.50`。
- 部署包：`releases/finance-platform-v10.50-local.tar.gz`，包含本地验证通过的预构建 `dist/`，服务器不再执行 Vite/esbuild 构建。

## 数据库、依赖与配置

- 本快照只记录从 v10.49 升级到 v10.50 的变化。
- 本版本不新增数据库表、字段、索引或迁移脚本，不执行 `drizzle schema push`。
- 本版本不新增 npm 依赖，不调整运行配置。
- “凭证名称”仅为 `bank_accounts.account_alias` 的页面业务名称变化，不重命名数据库字段，不需要数据迁移。
- v10.48 的月归档索引灰度和正式清理不是本版迁移，继续按 `docs/DEPLOY_v10.48-local.md` 的数据库状态与观察窗口独立执行。

## 风险与回退

- 中国银行备注仅在清理空格后为空时回退业务类型；已有非空备注始终优先，避免改变现有摘要。
- 利息摘要预览读取当前模板和流水变量；模板摘要为空时弹窗显示 `-`，应先维护利息模板再制单。
- “凭证名称”只改变页面和校验提示；外部接口调用方仍需提交 `accountAlias`，数据库仍保存 `account_alias`。
- 入账明细的项目资金和管理费展示调整不改变历史数据与汇总统计，回退代码后原金额会重新显示。
- 代码可使用 `releases/finance-platform-v10.49-local.tar.gz` 回退；本版没有数据库结构变化，无需数据库回滚。
- 部署脚本使用本轮固定 `dist` 备份原子切换；暂存校验、启动或 HTTP 健康检查失败时恢复本轮部署前产物。
