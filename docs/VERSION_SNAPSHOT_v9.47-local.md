# v9.47-local 版本快照

## 到账信息汇总

- 到账信息新增 `明细匹配到账方式`，选项为 `单笔匹配`、`同日汇总匹配`，默认 `单笔匹配`。
- 到账信息新增地区字段：到账认账时页面显示为 `渠道认账地区`，明细认账时页面显示为 `到账地区`，选项为 `北京市`、`外省市`、`港澳台`、`境外`、`内部客商`。
- 已记录到账信息列表展示匹配方式和地区。
- 非明细认账类型固定按 `单笔匹配` 保存，避免影响到账认账规则。

## 明细认账

- 当明细认账到账信息选择 `同日汇总匹配` 时，系统会先汇总同日、同到账信息、未认账的所有银行到账流水，判断订单明细总额是否可认。
- 认账执行仍按每条银行流水各自的认账任务进入队列，每个任务只按本条银行流水金额消耗未认账明细。
- 单条银行流水满额认账后标记为已认账；如果只消耗部分金额，则该流水任务保持部分认账。
- 明细认账生成入账结果时，会把到账信息配置的 `到账地区` 写入入账结果。
- 到账认账的渠道捐赠生成入账结果时，会把到账信息配置的 `渠道认账地区` 写入入账结果。
