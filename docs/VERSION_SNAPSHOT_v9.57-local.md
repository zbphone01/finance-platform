# v9.57-local 版本快照

## 发布范围

- 本版用于替代 v9.56-local 包，包含 v9.57 本轮修正以及 v9.55、v9.56 既有修正。
- 部署包：`releases/finance-platform-v9.57-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 明细分账开关

- 明细认账规则新增 `明细分账` 开关。
- 开关关闭时，`明细分账判断字段`、`判断关键字`、`明细匹配字段` 不可填写，也不会参与订单明细上传预匹配。
- 开关打开时，三项字段必填；前端保存和后端接口都会校验。
- 订单明细上传和手动开始认账补匹配时，只有开启 `明细分账` 才会执行 `待拆分` 预匹配。
- 历史已有完整单条多分账配置的规则，迁移后自动开启 `明细分账`。

## 订单明细包汇总

- 修复从 `订单明细包` 列表进入 `订单明细内容` 时，顶部汇总只显示主文件金额的问题。
- 当页面处于整包视图时，顶部 `条目数`、`匹配`、`未匹配`、`待拆分`、`订单总金额` 使用当前数据包整包汇总。
- 单文件查看仍显示单个文件自身汇总。

## 异常包判断

- 修复金额为 `0.01` 的打包订单明细被误判为 `订单总金额为0` 的问题。
- 异常判断从 `<= 0.01` 收紧为真正接近 `0.00`，避免 1 分钱订单包被标记为异常并从后续查询、认账中排除。

## 数据库迁移

- `migrate-v9.57-detail-split-enabled.sql`
  - `recognition_rules` 新增 `detail_split_enabled`。
  - 对历史三项明细分账配置完整的规则回填 `detail_split_enabled=1`。

## 延续约束

- `订单明细包` 列表继续读取 `order_files` 缓存字段，不在列表首屏实时扫描大明细表。
- `认账及分账` 日期列表和日期详情继续读取 `recognition_date_summaries`。
- 明细认账规则列表的普通 `编辑` 入口必须保持整体编辑；单条件编辑只保留在规则详情页。

- `npm run build` 通过。
- `npm test -- api/lib/orderUploadStream.test.ts` 通过。
