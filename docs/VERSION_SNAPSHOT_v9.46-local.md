# v9.46-local 版本快照

## 公益平台与预算编码刷新

- 修复公益平台懒加载刷新问题：新增、编辑、删除平台项目名称或项目详情后，当前展开节点会自动重新加载。
- 修复预算编码懒加载刷新问题：新增、编辑、删除节点后，当前已展开节点会自动重新加载。
- 公益平台搜索补齐页面展示格式匹配，支持 `PM1911110_`、`PPxxxxxxx_`、公益平台展示名等格式。

## 到账认账规则

- 到账认账渠道捐赠分账布局与明细认账分账布局对齐。
- 到账认账规则页的项目树和公益平台树在窗口重新聚焦时自动刷新，便于另开窗口维护平台项目后回到规则页直接选择。
- 渠道捐赠管理费默认 `百分比`，数值 `5`。
- 银行直捐新增字段：`会员姓名`、`地区`、`匿名`。
- 银行直捐字段顺序调整为：`反馈类型`、`支出资金来源`、`地区`、`匿名`、`会员姓名`、`管理费`。
- 匿名改为下拉选择，默认 `否`。
- 管理费支持按 `百分比` 或 `金额` 填写。为兼容历史数据，数据库枚举值仍为 `比例` / `金额`，页面展示为 `百分比` / `金额`。

## 手动认账

- 手动认账渠道捐赠在管理费前新增 `地区` 字段，选项为 `北京市`、`外省市`、`港澳台`、`境外`、`内部客商`。
- 手动认账管理费默认 `百分比`，数值 `5`。
- 手动认账银行直捐同步到账认账银行直捐字段和顺序。
- 任务详情中的手动认账弹层同步以上调整。

## 入账结果

- 入账结果新增 `地区`、`匿名`、`会员姓名` 字段。
- 日入账明细列顺序调整为 `支出资金来源`、`地区`、`匿名`、`会员姓名`、`入账金额`。
- 到账认账和手动认账生成入账结果时，会保存新增字段和管理费类型信息。

## 数据库迁移

- 新增迁移脚本 `migrate-v9.46-income-direct-donation-fields.sql`。
- 迁移为 `income_rule_splits` 新增：
  - `member_name`
  - `region`
  - `is_anonymous`
  - `management_fee_type`
  - `management_fee_value`
- 迁移为 `match_results` 新增同名字段，用于入账结果展示和保存。
- v9.46 依赖 v9.45 的 `match_results.management_fee_amount` 字段；如环境尚未执行 v9.45，需先执行 `migrate-v9.45-management-fee-amount.sql`。

## 部署影响

- 本版本包含数据库结构变更，部署新版代码前必须执行 v9.46 迁移。
- `package.json` 和锁文件未新增依赖。
- 沿用 `deploy-update-optimized.sh` 部署脚本。

## 验证

- `npm run check` 通过。
- `npm run build` 通过。
