# v9.76-local 版本快照

## 发布范围

- 本版用于替代 v9.75-local 包，包含登录页展示清理、手动开始认账入队过滤、已忽略订单取消忽略入口和状态列操作交互优化。
- 部署包：`releases/finance-platform-v9.76-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 登录页

- 去掉用户名输入框中的默认 `admin` 提示。
- 去掉密码输入框中的默认 `admin` 提示。
- 去掉登录按钮下方“测试阶段默认: admin / admin”说明。

## 手动开始认账

- “认账及分账”日期汇总点击“开始认账”时，明细认账队列只处理未认账或部分认账的流水任务。
- 全部银行流水都已认账的任务会跳过，不再重新加入明细认账队列。
- 部分认账流水仍可继续入队，补认剩余已匹配且未认账的订单明细。

## 已忽略订单

- 已忽略订单列表的状态列增加三个点操作入口。
- 可在单条已忽略订单上执行“取消忽略”，恢复为正常订单明细并刷新相关列表和任务汇总。
- 状态徽标只展示状态，只有三个点按钮可以打开操作菜单。

## 日期汇总订单明细

- 日期汇总详情的订单明细列表中，状态徽标不再作为操作触发区。
- 暂时忽略、转移日期、取消忽略、取消转移等操作统一只通过三个点按钮打开。

## 数据库迁移

- 本版不新增数据库迁移。
- 已部署 v9.75 的环境，直接部署 v9.76 代码即可。
- 从更旧版本升级时，仍需先补齐 `migrate-v9.70-detail-split-rule-upload-fields.sql` 和 `migrate-v9.74-finance-role.sql`。

## 验证

- `npm run check` 通过。
- `npm run build` 通过。
- `git diff --check` 通过。
- 发布包完整性检查通过，沿用历史轻量发布方式，不包含本地 `dist`，由服务器部署脚本重新构建。
