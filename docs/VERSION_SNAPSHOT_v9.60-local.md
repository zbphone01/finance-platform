# v9.60-local 版本快照

## 发布范围

- 本版用于替代 v9.59-local 包，包含明细认账规则编辑性能优化，以及订单明细包待拆分/未匹配明细入口拆分。
- 部署包：`releases/finance-platform-v9.60-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 明细认账规则编辑

- 保留普通编辑页 `/rules/edit/:id` 中所有条件和分账全部展开编辑的交互。
- 优化规则基本信息区域输入性能：规则名称、匹配到账信息、日期字段、收入字段、订单号字段、排除订单和明细分账字段输入时，不再重建下方全部条件/分账树形控件。
- 条件和分账自身变更时仍正常刷新对应编辑区域。
- 规则详情页中的 `编辑条件` 继续使用单条件编辑页。

## 订单明细包

- 操作列新增 `查看待拆分明细`，仅当数据包存在待拆分明细时显示。
- `查看待拆分明细` 进入详情页后只筛选 `pending_split` 明细。
- `查看未匹配明细` 仅当数据包存在未匹配明细时显示。
- `查看未匹配明细` 进入详情页后只筛选 `unmatched` 明细，不再混入待拆分明细。
- 订单明细包列表和详情页顶部统计均分别展示 `未匹配` 与 `待拆分` 数量。

## 数据库迁移

- 本版不新增数据库迁移。
- 部署前需确认目标环境已完成 v9.59 迁移：
  - `migrate-v9.59-detail-split-files.sql`
  - 如线上缺少 `exclude_order_enabled`，需补跑 v9.58 前置检查项 `migrate-v9.59-exclude-order-rule.sql`。

## 延续约束

- 明细认账规则普通编辑页必须保持整体展开编辑；不要改成摘要卡片或单条件跳转。
- 订单明细包列表的 `查看未匹配明细` 只对应 `unmatched`；`查看待拆分明细` 只对应 `pending_split`。

## 验证

- `npm run check` 通过。
- `npm run build` 通过。
