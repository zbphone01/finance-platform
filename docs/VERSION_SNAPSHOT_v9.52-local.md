# v9.52-local 版本快照

## 明细认账关键字匹配

- 上传订单明细时，明细认账规则预匹配改为系统级两段式匹配：先执行 `等于`，再执行 `包含`。
- `等于` 条件按 `关键字字段 + 关键字` 建立快速索引，减少大文件上传时逐行遍历全部条件的开销。
- 用户录入规则条件的先后顺序不再影响匹配优先级；精确匹配命中后不会被包含规则覆盖。
- 手动“开始认账”补匹配未匹配明细时，同样先跑 `等于`、再跑 `包含`。

## 明细认账执行性能

- 认账队列支持按任务去重；同一任务重复入队时合并等待者和执行选项，避免连续上传或重复点击导致重复执行。
- 手动开始认账保持“先补未匹配，再处理已匹配未入账明细”的顺序。
- 同日汇总匹配按规则条件分批处理，每批读取最多 5000 条明细的 `id` 和金额，累计到本次可认账额度后停止，不再一次性加载全部明细。
- 单笔匹配按规则条件先统计金额和条数，达到阈值后走按条件批量回写；小批量仍按明细 ID 分批回写，避免小任务使用过重路径。
- 单笔匹配大批量阈值：
  - 明细条数大于等于 5000；或
  - 条件命中金额大于等于 100000。
