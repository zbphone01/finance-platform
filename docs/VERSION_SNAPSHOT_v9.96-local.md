# v9.96-local 版本快照

## 发布范围

- 本版用于补齐日期汇总银行流水列表中的手动认账金额控制和快捷取消手动认账入口。
- 右上角系统版本号更新为 `v9.96`。
- 部署包：`releases/finance-platform-v9.96-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 认账及分账

- 日期汇总详情的银行流水列表中，已认账或部分认账且存在未锁定手动认账入账时，状态栏显示“取消手动认账”icon。
- 取消手动认账 icon 放在状态标志和制单 icon 之间；点击后弹窗确认，并仅取消该流水通过手动认账产生的未锁定入账。
- 取消手动认账完成后刷新日期汇总、银行流水、入账结果、凭证汇总等相关数据。
- 手动认账表单新增常驻“认账金额”输入，位置在“认账类型”和“分账设置”之间。
- 选择银行流水进行手动认账时，认账金额默认填入当前可认账金额。
- 确认认账时按输入金额生成入账，可用于只手动认账部分金额。
- 前端和后端均校验认账金额必须大于 0，且不能大于当前可认账金额；超过时不执行并提示。

## 数据库迁移

- 本版没有新增数据库迁移。
- 已部署 v9.95 的环境可直接部署 v9.96 代码。
- 如果目标环境尚未部署 v9.94，需要先执行 `migrate-v9.94-voucher-template-settings.sql`，再部署 v9.96。
