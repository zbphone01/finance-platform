# v9.75-local 版本快照

## 发布范围

- 本版用于替代 v9.74-local 包，包含已忽略订单处理、日期汇总明细筛选和银行到账上传提示优化。
- 部署包：`releases/finance-platform-v9.75-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 已忽略订单

- “认账及分账”页面新增“已忽略订单”入口，使用琥珀色描边按钮提示待关注入口。
- 新增已忽略订单列表页，展示日期汇总、订单日期/匹配日期、订单号、明细认账规则、认账关键字、订单金额、忽略原因和状态。
- 已忽略订单列表支持搜索日期、订单号、规则和订单金额。
- 已忽略订单列表支持勾选多条明细后批量转移日期。
- 系统因明细分账产生的拆分忽略记录不会进入已忽略订单列表，避免误操作。

## 日期汇总订单明细

- 日期汇总详情的订单明细汇总中，“未认账”数字可点击，点击后展开并显示未认账明细，包含待拆分。
- “未认账中待拆分”数字可点击，点击后展开并仅显示待拆分明细。
- 状态筛选中区分“未认账”和“未认账（不含待拆分）”，使汇总数字和列表筛选口径更清楚。

## 银行到账上传提示

- 添加银行到账成功后，改为弹窗提示，需要用户手动关闭。
- 上传结果弹窗展示新增流水数和生成任务数。
- 如果上传文件包含已上传过的流水，重复流水数量会合并展示在同一个弹窗中，不再连续出现两个提示。

## 数据库迁移

- 本版不新增数据库迁移。
- 已部署 v9.74 的环境，直接部署 v9.75 代码即可。
- 从更旧版本升级时，仍需先补齐 `migrate-v9.70-detail-split-rule-upload-fields.sql` 和 `migrate-v9.74-finance-role.sql`。

## 验证

- `npm run check` 通过。
- `npm run build` 通过。
- 发布包完整性检查通过，沿用历史轻量发布方式，不包含本地 `dist`，由服务器部署脚本重新构建。
- 发布包未包含 `node_modules`、`.upload-cache`、`releases` 等本地大目录。
