# v9.57.1-local 版本快照

## 发布范围

- 本版用于替代 v9.57-local 包，包含 v9.57.1 本轮修正以及 v9.57 既有修正。
- 部署包：`releases/finance-platform-v9.57.1-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 订单明细包整包详情

- 修复直接打开打包明细单文件 URL，例如 `/order-files/300` 时，顶部汇总仍显示单文件金额的问题。
- 对 `打包明细` 文件详情页，如果 URL 未携带整包参数，页面会自动按当前文件的 `匹配日期(upload_date) + 明细认账规则(rule_id)` 切换到整包口径。
- 直接访问、刷新、复制单文件 URL 后，顶部 `条目数`、`匹配`、`未匹配`、`待拆分`、`订单总金额` 都应与整包明细一致。

## 延续修正

- 继续保留 v9.57 的 `明细分账` 开关逻辑。
- 继续保留 v9.57 的订单明细包整包汇总接口。
- 继续保留 v9.57 的 `0.01` 小额订单包不误判异常修复。

## 数据库迁移

- 本版不新增数据库迁移。
- 首次部署 v9.57 系列时仍需执行 `migrate-v9.57-detail-split-enabled.sql`。

## 验证

- `npm run check` 通过。
- `npm run build` 通过。
