# v9.44.1-local 版本快照

## 明细认账规则条件导入/导出

- 明细认账规则页的导入/导出从整批规则 JSON 改为所选规则的条件内容 CSV。
- 点击 `导出条件` 后在弹窗中选择规则，导出该规则下的条件和分账明细。
- 点击 `导入条件` 后在弹窗中选择规则，再选择 CSV 文件；导入会替换所选规则当前条件内容。
- CSV 一行对应一条分账明细，包含条件序号、分账序号、关键字字段、关键字、分账比例、收入类型、收入属性、收入部门、预算编码、NC项目名称、平台项目名称、平台项目详情、管理费比例、支出资金来源。
- 导入继续复用规则条件校验：重复关键字不允许，单个条件下分账比例合计必须为 100%。

## 部门初始数据

- 部门模块去掉手动 `初始化预设部门` 入口。
- 首次部署或部门表为空时，进入部门管理页面自动初始化当前默认部门结构。
- 自动初始化由后端幂等接口保护：仅部门表为空时插入，已有部门数据时不做变更。

## 部署影响

- 本版本没有新增数据库迁移。
- `package.json` 和锁文件未新增依赖；沿用优化部署脚本即可。
- 部门初始数据通过应用接口自动写入，不需要额外 SQL。
