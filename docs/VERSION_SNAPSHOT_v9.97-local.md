# v9.97-local 版本快照

## 发布范围

- 本版用于新增角色权限配置，并优化凭证汇总中的银行流水展示。
- 右上角系统版本号更新为 `v9.97`。
- 部署包：`releases/finance-platform-v9.97-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 账号与权限

- 新增 `role_permissions` 角色权限配置表，用于维护运营人员和财务人员的功能权限。
- 账号管理页新增权限配置入口，管理员可按角色维护账号管理菜单、财务凭证信息菜单、删除类操作、取消手动认账和制单权限。
- 左侧菜单、页面入口和操作按钮会按角色权限展示或禁用。
- 后端同步校验对应权限，避免仅依赖前端隐藏操作。
- 默认权限：运营人员不可删除、不可取消手动认账、不可制单；财务人员默认可制单、可访问财务凭证信息。

## 凭证汇总

- 凭证汇总列表的“银行流水”列改为显示真实关联流水号。
- 同日汇总凭证会按凭证关联流水顺序展示为 `流水号1，流水号2，流水号3`，不再显示“同日汇总 N 笔银行到账”。

## 数据库迁移

- 本版新增数据库迁移：`migrate-v9.97-role-permissions.sql`。
- 已部署 v9.96 的环境，部署 v9.97 代码前需要先执行该迁移。
- 如果目标环境尚未部署 v9.94，需要先执行 `migrate-v9.94-voucher-template-settings.sql`，再按版本顺序补齐后续迁移。
