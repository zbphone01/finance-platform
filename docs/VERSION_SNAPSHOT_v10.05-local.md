# v10.05-local 版本快照

## 发布范围

- 本版用于修复认账及分账差异大状态展示、差额金额候选查找，以及捐赠活动导入导出和弹窗提示。
- 右上角系统版本号更新为 `v10.05`。
- 部署包：`releases/finance-platform-v10.05-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 认账及分账

- 日期汇总详情读取银行流水时，保护已标记为“差异大”的流水状态，不再同步回普通“未认账”。
- 上传订单明细完成后，同时刷新认账及分账列表、日期汇总详情和银行流水列表缓存，减少进入详情时短暂看到旧状态的问题。
- 差额金额查找改为先查同金额单条订单明细；未找到同金额明细时，再查找可组合为差额的订单明细。
- 修复 0.10 等小额差异存在同金额订单明细时仍提示“未找到可组合订单”的问题。

## 捐赠活动

- 新增或编辑捐赠活动时，编号重复等保存错误改为显示在弹窗内部，避免右上角提示被弹窗遮挡。
- 根级活动说明导出时，分类列留空、活动说明列填写对应编号和名称。
- 新版导出的捐赠活动文件可直接回导，空分类的活动说明会按根级活动说明入库。

## 数据库迁移

- 本版无新增数据库迁移。
- 如目标环境尚未部署 v10.04，需要先按 v10.04 文档补齐 v10.00、v10.01、v10.02 迁移。

## 本地验证

- `npm run check` 通过。
- `npm run lint` 通过。
- `npm run build` 通过。
- `git diff --check` 通过。
- `releases/finance-platform-v10.05-local.tar.gz` 已生成并通过完整性检查。
