# v10.32-local 版本快照

## 发布范围

- 本版覆盖订单明细后台上传进度、全类型认账取消、订单明细手动认账收款渠道自动取值，以及非模板收入类型的手工凭证录入与取消。
- 右上角系统版本号更新为 `v10.32`。
- 部署包：`releases/finance-platform-v10.32-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 订单明细后台上传

- 浏览器完成文件分片上传并确认服务端进入队列后，上传弹窗立即关闭，文件解析、入库和匹配认账规则继续在后台执行。
- 认账及分账页保留用户未完成的后台上传任务，刷新或重新进入页面后继续轮询。
- 后台任务分别显示“读取并解析订单明细”和“入库并匹配认账规则”两条进度，不再用单一百分比混合两个阶段。
- 处理完成后自动刷新日期汇总、银行流水和订单明细包；失败任务保留错误信息供用户关闭。

## 全类型取消认账

- 入账结果页的“取消认账”从仅支持手动认账扩展为支持到账认账、明细认账、订单明细手动认账和银行流水手动认账。
- 取消范围按一次认账生成的整组分账结果计算，不允许只删除单条分账行。
- 整组任一结果已锁定或已生成凭证时阻止取消。
- 已归档的明细认账先在归档日期锁内恢复到热表，再回滚认账、刷新文件与日期快照。
- 权限配置文案从“手动认账取消”改为“取消认账”，权限键保持 `manual_recognition_cancel` 兼容现有配置。

## 订单明细手动认账

- 页面去掉“认账信息”标题和“收款渠道”选择。
- 收款渠道由服务端按“订单明细所属规则 -> 匹配到账信息 -> 凭证收款渠道”自动获取，前端不再传入可更改的渠道编号。
- 未配置渠道时沿用原有可空口径；已配置但渠道已删除时阻止写入失效编号。

## 手工凭证

- `政府补助`、`个税返还`、`本金`、`投资收益`、`利息`、`其他收入`、`其他` 不生成模板凭证行，制单时按收入类型汇总金额并逐类填写文本凭证 ID。
- `捐赠收入`、`会费收入` 继续按现有模板自动生成，`订单退款` 继续随自动凭证处理。
- 所有入账结果都完成制单后，流水状态统一显示“已认账/已制单”，不再显示带星号的部分制单状态。
- 历史已生成自动凭证但尚有非模板收入待制单的流水，可重新点击制单补录凭证 ID。
- 凭证汇总中每个手工凭证独立成行，凭证 ID 显示填写文本，凭证金额显示该收入类型的汇总金额，不提供“查看凭证”。
- 日期汇总状态菜单可选择单张手工凭证取消；凭证汇总的手工凭证行也可直接取消。取消时只恢复对应流水范围和收入类型，其他手工凭证和自动凭证不受影响。
- 批量制单遇到需要填写文本凭证 ID 的流水时跳过并提示逐笔处理。

## 数据库迁移

- 本版新增 `migrate-v10.32-manual-income-vouchers.sql`。
- 迁移为 `voucher_results` 新增凭证类型、幂等键、文本凭证 ID、收入类型、凭证金额和创建批次字段。
- `voucher_result_flows` 从“每条流水只能关联一张凭证”改为“同一凭证与同一流水唯一”，允许同一流水同时关联自动凭证和多张手工凭证。
- 本地沙箱已执行迁移并确认字段、幂等唯一索引和凭证-流水复合唯一索引存在。
