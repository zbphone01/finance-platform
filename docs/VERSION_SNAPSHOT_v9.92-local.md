# v9.92-local 版本快照

## 发布范围

- 本版用于优化认账及分账中大订单明细包的操作反馈、开始认账即时状态展示，以及账单日期删除的可观测流程。
- 右上角系统版本号更新为 `v9.92`。
- 部署包：`releases/finance-platform-v9.92-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 日期汇总删除

- 认账及分账列表删除账单日期任务改为步骤式删除会话，前端展示真实删除阶段：
  - `1/5 正在回滚分账包状态`
  - `2/5 正在删除入账结果`
  - `3/5 正在删除订单明细包`
  - `4/5 正在删除银行到账`
  - `5/5 正在删除账单日期任务`
- 删除期间弹窗不可关闭，并禁用上传、开始认账和其它删除操作，避免重复触发。
- 后端删除前会校验已制单锁定记录，存在锁定时阻止删除。
- 删除逻辑先回滚/解绑关联明细分账状态，再删除入账结果、订单明细包、银行到账和账单日期任务。
- 删除完成后前端会刷新日期汇总列表，并确认当前条目不再显示后再提示成功。

## 操作反馈

- 日期汇总详情的订单明细列表中，点击“暂时忽略”后立即显示不可关闭的处理中弹窗：
  - `忽略处理中，请稍后`
- 忽略请求完成后弹窗自动关闭，并保留原有列表刷新和成功提示。
- 认账及分账列表点击“开始认账”并确认后，当前日期汇总行会临时显示为“认账执行中”，后台返回后再刷新为真实状态。

## 技术说明

- 本版没有新增数据库迁移。
- 删除任务新增内存态删除会话状态，用于前端轮询展示当前删除步骤。
- 旧的同步 `deleteTask` 接口继续保留，但内部复用新的步骤式删除逻辑。
