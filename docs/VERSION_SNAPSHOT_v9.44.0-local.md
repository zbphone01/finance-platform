# v9.44.0-local 版本快照

## 入账结果操作

- 入账结果菜单当天明细的单条 `制单 / 取消制单` 操作改为图标按钮，状态口径不变。
- 手动认账生成且尚未制单的入账结果增加 `取消认账` 操作。
- 取消认账按入账结果行回退：删除该条结果，关联银行流水恢复为可继续认账，并刷新认账任务状态和日期汇总。
- 自动到账认账、明细认账和已制单入账结果不支持取消认账，前后端均限制。

## 部署影响

- 本版本没有新增数据库迁移。
- `package.json` 和锁文件未新增依赖；沿用优化部署脚本即可。
