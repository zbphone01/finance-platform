# v10.04-local 版本快照

## 发布范围

- 本版用于优化认账及分账日期汇总详情、异常金额候选忽略、凭证取消和订单明细上传批次。
- 右上角系统版本号更新为 `v10.04`。
- 部署包：`releases/finance-platform-v10.04-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 认账及分账

- 日期汇总详情的入账结果列表改为小号字体，并参考入账结果菜单的入账明细列风格展示。
- 日期汇总详情的入账结果列表隐藏入账时间、流水号、项目资金、管理费和状态列。
- 银行流水列表中，部分认账的待认账金额改为蓝色系，和异常差额红色区分更明显。
- 银行流水列表的差额金额数字支持点击查找可忽略候选订单明细。
- 候选订单明细仅从被点击流水同日期、同规则的匹配订单明细包范围查找。
- 整数差额查找同金额单条订单明细；带小数差额查找多个小数金额订单组合。
- 候选弹窗支持人工勾选确认后批量忽略。
- 候选弹窗修复内容溢出问题，并精简列表列为订单号、认账关键字和订单金额。

## 凭证

- 修复取消凭证后，合并凭证行中的退订/订单退款入账结果仍保持锁定的问题。
- 取消凭证时会同时回退该凭证关联银行流水下所有已锁定入账结果。

## 订单明细上传

- 订单明细上传服务端分批入库从每 5000 行调整为每 10000 行。
- 上传订单明细弹窗提示文案同步更新为每 10000 行分批入库。

## 数据库迁移

- 本版无新增数据库迁移。
- 如目标环境尚未部署 v10.03，需要先按 v10.03 文档补齐 v10.00、v10.01、v10.02 迁移。

- `npm run build` 通过。
- `git diff --check` 通过。
- `releases/finance-platform-v10.04-local.tar.gz` 已生成并通过完整性检查。
