# v9.37.0-local 版本快照

## 明细包类型

- 到账信息汇总新增 `明细包类型`，仅在认账类型为 `明细认账` 时选择。
- 明细包类型取值：`T+1`、`打包明细`。
- 已记录列表的认账类型显示为 `明细认账（T+1）` 或 `明细认账（打包明细）`。
- 新增数据库字段：
  - `counterparty_records.detail_package_type`
  - `order_files.detail_package_type`
  - `order_files.upload_date`

## 订单明细上传与认账

- 上传订单明细时，根据所选明细认账规则匹配到账信息里的明细包类型生成数据包。
- `T+1` 继续按原规则生成数据包：订单真实日期 + 1 对应银行到账日期。
- `打包明细` 不拆分订单日期，按上传日期生成独立数据包，对应当天银行到账认账。
- 明细认账执行时按规则对应的包类型读取订单明细，避免 T+1 明细和打包明细混用。

## 订单明细与日期汇总展示

- 订单明细菜单表头改为 `订单日期/上传日期`，第二列展示 `明细包类型`。
- 订单明细数据包删除范围调整为 `订单日期/上传日期 + 明细包类型 + 明细认账规则`。
- 日期汇总页主 tab 仍显示 `订单明细`。
- 点击 `订单明细` 后，使用 `T+1明细`、`打包明细` 两个子 tab 分别展示。
- 日期汇总订单明细列表去掉 `明细包类型` 列，当前类型由子 tab 表示。

## 公益平台删除保护

- 认账信息设置 -> 公益平台中，平台项目名称下已有项目详情时，不允许删除。
- 前端点击删除会提示 `该平台项目名称下已有项目详情，不能删除`。
- 后端 `deletePlatformProject` 接口也校验项目详情数量，防止绕过页面误删。
