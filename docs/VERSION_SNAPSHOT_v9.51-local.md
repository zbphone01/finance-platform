# v9.51-local 版本快照

## 到账信息匹配条件

- 到账信息汇总新增多组匹配条件，一个到账别称可以维护多个对方账号、对方户名、用途关键字、附言关键字组合。
- 历史到账信息通过 `counterparty_match_accounts` 自动初始化一组匹配条件，保持原有匹配口径不变。
- 未记录到账信息识别、到账信息去重、到账认账规则和明细认账规则统一使用多组匹配条件。
- 解决支付宝等同一到账信息可能存在多个对方账号时，明细认账无法覆盖全部银行流水的问题。

## 同日汇总明细认账

- 同日汇总匹配模式下，上传订单明细包后，会把同一到账信息命中的多条银行流水任务统一绑定到明细认账规则后再入队。
- 修复只有第一条银行流水绑定规则、后续银行流水入队后提示“请先为此任务配置认账规则”的问题。
- 汇总到账金额大于订单明细包已匹配金额时，按银行流水顺序消耗已匹配未认账订单金额。
- 前序小额流水可按流水金额认满并置为已认账，最后一条大额流水承接剩余订单金额并保留部分认账。
- 银行流水列表支持显示“认账执行中”，不再只显示未认账或部分认账。

## 认账队列

- 队列任务入队前先把任务状态更新为认账执行中，前端轮询可以立即看到后台执行状态。
- 后台认账失败时，任务状态会落到失败，避免一直停留在认账执行中。

## 数据库迁移

- 新增迁移：`migrate-v9.51-counterparty-match-accounts.sql`
- 新增表：`counterparty_match_accounts`
- 迁移会从 `counterparty_records` 初始化历史匹配条件。
