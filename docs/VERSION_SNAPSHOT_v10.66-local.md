# v10.66-local 版本快照

## 发布范围

- 本版本从 `v10.64-local` 升级，一次包含尚未单独发布的 v10.65 票据单号字段配置和 v10.66 文件级索引任务。
- 明细认账规则基本信息底部新增“票据用单号”，可选填财务流水号、业务流水号、商户订单号在订单明细文件中的原始列名；历史规则默认全部为空。
- 上传订单明细时，已配置字段必须存在于文件表头；只把对应非空值补入 `bill_details.raw_data`，未配置或单行空值不增加保存内容。
- 正常订单文件上传完成后只写入一条 `invoice_order_index_jobs` 文件级任务，并固化上传时的主订单号及三类票据单号字段快照；不在上传链路逐行维护票据索引。
- 任务写入异常不会回滚已完成的订单上传，票据系统会低频补扫已完成但缺失任务的文件。
- 订单跨日期转移或取消转移时，按明细 ID 更新已有票据索引的分区定位；票据索引表尚未部署或临时不可用时不阻断认账操作。
- 规则新建、编辑、复制、草稿恢复和查看页均支持三项配置；界面说明为“填写开票可能用到的流水字段”，输入框不额外显示字段标签。
- 右上角系统版本号更新为 `v10.66`。
- 部署包：`releases/finance-platform-v10.66-local.tar.gz`，包含本地验证通过的预构建 `dist/`。

## 数据库、依赖与配置

- 迁移顺序固定为：`migrate-v10.65-invoice-order-no-fields.sql`，再执行 `migrate-v10.66-invoice-order-index-jobs.sql`。
- v10.65 为 `recognition_rules` 新增三个可空 `varchar(100)` 字段：`invoice_financial_flow_no_field`、`invoice_business_flow_no_field`、`invoice_merchant_order_no_field`。
- v10.66 新增 `invoice_order_index_jobs`，以 `order_file_id` 唯一保存文件级状态、配置快照、分区游标、租约、计数和错误信息，并通过外键在订单文件删除时级联清理。
- 票据系统实际使用的 `invoice_order_identifiers` 由票据系统 v0.1.6 迁移创建，不属于认账系统本次迁移。
- 本版本不修改 `bill_details` 表结构或现有索引，不新增 npm 依赖、环境变量或运行配置。
- 本地共享数据库已执行 v10.65、v10.66 迁移；历史规则三项配置保持为空，历史订单文件任务由票据系统工作器自动补建。

## 风险与回退

- 新版代码部署前必须先执行两个认账迁移；否则规则保存或文件任务入队会因缺少结构失败。
- 三项原始列名配置会成为上传必需表头，配置错误时订单文件会在入库前明确失败，不产生部分索引数据。
- 文件任务写入只增加一次小表写操作；票据侧索引扫描由共享命名锁控制并按小批次执行，认账任务具有优先权。
- 应用回退到 `v10.64-local` 时保留三个规则字段和 `invoice_order_index_jobs`；旧版本不会读取这些结构，保留不会影响原有认账。
- 若票据系统 v0.1.6 仍在运行，不要删除任务表或规则字段。完全删除新增结构属于破坏性回退，必须先停止票据工作器并另行审核。
