# v9.45-local 版本快照

## 管理费金额

- `match_results` 新增 `management_fee_amount` 字段，用于保存每条入账结果的管理费金额。
- 管理费金额在入账结果生成时计算，口径为 `入账金额 split_amount × 管理费比例 management_fee_ratio / 100`，保留两位小数。
- 明细认账、到账认账、手动认账三条写入路径均已同步计算管理费。
- 新增迁移脚本 `migrate-v9.45-management-fee-amount.sql`，用于新增字段并回填历史入账结果。

## 入账结果页面

- 日入账明细新增“管理费”列，位于“入账金额”右侧。
- “管理费”显示两位小数。
- “入账金额”列取消右侧固定，仅保留“状态”和“操作”固定列。

## 入账汇总

- 新增菜单“入账汇总”，位于“入账结果”下方。
- 新增页面 `/result-summary`。
- 查询条件包括年份、部门、汇总口径。
- 部门选择使用已有树形部门组件，支持清除选择后查看全部部门。
- 汇总口径支持“预算编码”和“支出资金来源”。
- 查询结果展示入账记录数、入账金额、管理费，并展示顶部合计。
- 汇总计算在数据库中完成，避免前端拉取明细后计算。

## 部署影响

- 本版本包含数据库结构变更，部署新版代码前必须执行 `migrate-v9.45-management-fee-amount.sql`。
- `package.json` 和锁文件未新增依赖。
- 沿用 `deploy-update-optimized.sh` 部署脚本。
