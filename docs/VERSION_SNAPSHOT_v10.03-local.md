# v10.03-local 版本快照

## 发布范围

- 本版用于优化订单明细手动认账、认账规则下拉体验，以及捐赠活动导入导出。
- 右上角系统版本号更新为 `v10.03`。
- 部署包：`releases/finance-platform-v10.03-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 订单明细手动认账

- 日期汇总的订单明细列表中，未认账明细支持从状态列操作进入手动认账。
- 手动认账改为单独页面，页面分为订单信息和认账信息两个模块。
- 订单信息展示订单号、订单金额、匹配的银行流水号。
- 手动认账后的明细支持从状态列取消认账。

## 认账规则设置

- 分账设置中的支出资金来源文案调整为“支出资金来源（选择捐赠活动自动生成） *”。
- 捐赠活动树状下拉增加搜索能力。

## 捐赠活动

- 同一分类下添加或编辑相同活动说明时，会正常提示重复错误。
- 新增导入、导出功能。
- CSV 列为：分类编号、分类、活动说明编号、活动说明。
- 活动说明编号支持 3 至 6 位数字或字母。

## 数据库迁移

- 本版无新增数据库迁移。
- 如目标环境尚未部署 v10.02，需要先按 v10.02 文档补齐 v10.01、v10.02 迁移。

## 本地验证

- `npm run check` 通过。
- `npm run build` 通过。
- `git diff --check` 通过。
- `releases/finance-platform-v10.03-local.tar.gz` 已生成并通过完整性检查。
