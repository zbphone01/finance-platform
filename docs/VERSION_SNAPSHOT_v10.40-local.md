# v10.40-local 版本快照

## 发布范围

- 明细分账包删除过程中显示“删除中”，并禁用列表内全部操作；删除成功后继续直接移除列表条目并在右上角提示。
- 明细分账首次上传时预加载 XLSX 解析组件，加载、校验和上传阶段提供明确状态，并阻止重复点击造成重复上传。
- 删除订单明细包弹窗移除右上角关闭按钮；删除开始前仍可使用取消按钮，删除过程中继续强制保持弹窗。
- 订单明细后台入库改为状态筛选行右侧的紧凑提示，显示文件名和实际已入库行数；完成后隐藏并沿用右上角提示，失败信息继续保留。
- 新生成凭证的汇总行结算方式固定为 `203_网上银行`；广发银行、工商银行分别生成指定银行账户说明。
- 右上角系统版本号更新为 `v10.40`。
- 部署包：`releases/finance-platform-v10.40-local.tar.gz`。

## 上传与删除交互

- 明细分账包删除请求处理中，开始认账、查看、查看未匹配明细和删除等操作统一禁用，避免并发操作同一列表。
- 明细分账 XLSX 解析组件随上传弹窗打开预加载；组件未就绪时展示加载提示并禁用文件、规则和提交操作。
- 上传提交使用同步引用锁和上传状态双重防重，首次点击即进入处理中，避免连续点击创建多个上传会话。
- 订单明细后台入库提示不再展示读取解析及入库百分比，只展示服务器实际返回的 `processedRows` 行数。
- 过长文件名继续在紧凑状态标签内缩略，并通过悬停标题查看完整文件名，避免挤压状态筛选区域。

## 凭证汇总说明

- 汇总行的结算方式在制单时统一写入 `203_网上银行`。
- 到账银行为广发银行时，银行账户写入 `广发银行1333账号`；到账银行为工商银行时，写入 `工商银行0733账号`；其他银行暂显示 `-`。
- 说明写入 `voucher_result_lines.explanation_json` 快照，仅影响新制凭证，历史凭证不自动回填。

## 数据库与依赖

- 本版不新增数据库迁移；已部署 v10.39 的环境可直接部署 v10.40 代码包。
- v10.36 环境仍需先按 v10.38 部署说明执行 v10.37 上传快照重建和 v10.38 明细分账进度迁移，再部署 v10.40。
- 本版不新增依赖，不调整配置，不执行 `drizzle schema push`。
