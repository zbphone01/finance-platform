# v9.85-local 版本快照

## 发布范围

- 本版用于明确入账结果锁定与制单功能的业务边界。
- 本版新增数据库迁移：`migrate-v9.85-counterparty-voucher-summary.sql`。
- 部署包：`releases/finance-platform-v9.85-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 入账结果锁定

- `入账结果` 菜单中的 `锁定 / 取消锁定` 只用于锁定认账结果。
- 锁定后的认账结果继续阻止相关银行到账、订单明细、明细分账被删除，避免误删已确认的认账数据。
- 锁定状态不代表已经制单，也不作为后续真正制单功能的完成状态。
- 前端调用改为认账结果锁定接口命名；旧制单命名接口保留兼容。

## 制单功能

- 真正的制单功能与入账结果锁定解耦，后续单独开发。
- 现有 `制单结果` 入口保持原有占位能力，不使用入账结果锁定状态作为制单结果。
- 日期汇总银行流水列表先实现前端制单交互：已认账流水可点击制单图标，生成后状态展示为 `已认账/已制单`。
- `已认账/已制单` 支持查看制单和取消制单；查看制单进入整页表格。
- 查看制单页按银行流水读取入账结果预览；一条入账结果生成两条制单行。
- 第一条摘要按 `制单摘要 + 订单明细数 + 笔数-平台项目详情(用于NC项目名称)` 拼接。
- 第二条摘要按 `结转管理费比例%管理费-平台项目详情(用于NC项目名称)(公益平台名称)` 拼接。
- 查看制单新增 `序号` 列，按最终制单行从 `1` 连续编号；同一入账结果生成的两条制单行编号连续，摘要中不包含序号。
- 两条制单行的贷方金额分别读取入账结果中的入账金额和管理费金额；科目和借方金额暂以 `-` 占位。
- 点击制单时只校验该银行流水是否存在已认账入账结果；如果到账信息未填写制单摘要，第一条摘要以前缀为空继续拼接订单笔数和项目信息。
- 当前前端制单交互会在点击制单时保存一份制单预览快照，查看制单优先展示该快照；未生成快照时才兜底实时预览。
- 到账信息汇总的记录/编辑弹窗顶部显示到账别称，底部支持维护制单摘要内容；该内容保存到到账信息自身字段中，生成制单时无需再反查独立制单摘要表。
- 左侧不再显示独立 `财务信息设置 -> 制单摘要` 维护入口，制单摘要统一在到账信息汇总中维护。
