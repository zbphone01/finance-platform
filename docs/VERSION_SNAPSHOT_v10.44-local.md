# v10.44-local 版本快照

## 发布范围

- 工商银行到账流水修正字段映射：`对方行名`写入“对方开户行”，`对方行号`写入“交易行所”。
- 到账认账规则取消自定义匹配入口；新建、编辑和复制必须选择认账类型为“到账认账”的已记录到账信息。
- 到账认账执行时始终读取已记录到账信息当前启用的多组对方账号、对方户名、摘要、用途和附言条件；未配置摘要、仅配置对方账号的到账信息也能正常认账。
- 历史未关联到账信息的自定义到账认账规则继续按原字段执行，避免已有规则突然失效。
- 捐赠收入“银行直捐”在到账认账规则和手动认账中恢复选填会员姓名，并新增“所属项目中心”；填写会员姓名时所属项目中心必填。
- 入账结果、日期任务详情和到账认账规则详情新增所属项目中心展示。
- v10.43 MySQL Event 开始时间计算改为日期与时间分离处理，避免数据库与连接排序规则不一致时出现 `Illegal mix of collations`。
- 右上角系统版本号更新为 `v10.44`。
- 部署包：`releases/finance-platform-v10.44-local.tar.gz`。

## 数据库与迁移

- 新增迁移 `migrate-v10.44-bank-direct-member-project-center.sql`。
- `income_rule_splits` 新增可空字段 `project_center VARCHAR(255)`，保存到账认账规则分账的所属项目中心。
- `match_results` 新增可空字段 `project_center VARCHAR(255)`，保存入账结果快照。
- 历史规则和历史入账结果不回填所属项目中心。
- 从 v10.43 升级只需执行 v10.44 迁移。
- 从 v10.42 升级需先执行修正版 v10.43 迁移，再执行 v10.44 迁移。
- 本版不执行 `drizzle schema push`。

## 到账认账规则

- 页面不再展示或提交规则自身的对方户名、用途、附言自定义字段。
- 规则列表和详情改为展示匹配到账信息。
- 已记录到账信息是新规则唯一匹配来源；匹配条件更新后无需重新保存到账认账规则。
- 规则匹配优先级按到账信息各组中已填写条件数量计算。

## 银行直捐会员信息

- 会员姓名仍为选填。
- 填写会员姓名时必须从部门管理 `01` 一级部门直属的启用二级部门中选择所属项目中心。
- 保存时按当前部门名称规范化为 `编码_名称`，避免使用过期部门名称。
- 会费收入原有会员姓名、缴纳年限要求不变。

## 风险与回退

- 未执行 v10.44 迁移就部署代码会因缺少 `project_center` 字段导致规则保存或结果查询失败。
- v10.44 两个新增字段均可空，代码回退到 v10.43 时字段可以保留，不建议为了回退立即删除字段。
- 从 v10.42 跨版本升级时，v10.43 迁移包含历史数据搬迁和分区 DDL，必须在维护窗口执行并提前备份。
- 代码可使用 `releases/finance-platform-v10.43-local.tar.gz` 回退；已完成的 v10.43 分区结构不能仅通过回退代码撤销。
