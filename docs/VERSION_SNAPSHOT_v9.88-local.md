# v9.88-local 版本快照

## 发布范围

- 本版用于优化银行到账上传提示、入账结果展示与大订单明细上传处理。
- 本版无新增数据库迁移；从 v9.87 升级可直接部署代码包。
- 部署包：`releases/finance-platform-v9.88-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 银行到账上传

- 上传完成后的弹窗不再展示新增任务数。
- 弹窗统一提示本次上传了多少条有效流水，避免与任务生成数量产生误解。

## 入账结果

- 管理费计算规则调整：
  - 大于等于 1 分的金额，只保留精确到分的金额，例如 `0.016` 取 `0.01`。
  - 小于 1 分的金额，按厘四舍五入，例如 `0.005` 取 `0.01`，`0.004` 取 `0.00`。
- 入账结果增加 `项目资金` 列，展示在 `入账金额` 右侧。
- `项目资金 = 入账金额 - 管理费`。
- 入账汇总、日期入账明细、任务详情中的相关金额展示同步补充项目资金。

## 入账结果筛选

- 入账结果菜单的日期入账明细列表增加类型筛选。
- 默认展示全部，可筛选 `捐赠收入` 和 `订单退款`。

## 订单明细上传

- 大订单明细上传后不再把所有分片合并成一个大文件。
- 后端改为按已上传分片顺序读取和解析，减少一次大文件合并带来的硬盘写入。
- 保留原有服务器处理进度能力，进度来源仍为后端实际读取和处理状态。

## 处理优化

- 订单明细处理时减少重复汇总扫描，部分任务汇总改为一次聚合查询。
- 同一轮处理内避免对同一任务重复刷新汇总。
- 未来数据库统计信息评估事项已记录到 `docs/迭代备忘.md`。
