# v9.71-local 版本快照

## 发布范围

- 本版用于替代 v9.70-local 包，包含明细分账、订单明细包删除/重传、认账任务和日期汇总快照的稳定性修复。
- 部署包：`releases/finance-platform-v9.71-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 明细分账

- 删除明细分账包后，来源订单明细会从自动拆分忽略恢复为 `待拆分`，并清空认账结果字段。
- 删除明细分账包后，会同步重算来源任务的银行流水认账状态和任务状态，避免来源任务仍停留在部分认账。
- 明细分账认账完成后，前端会立即刷新明细分账、订单明细包、认账及分账列表和任务详情缓存，减少跨菜单状态延迟。

## 订单明细包

- 删除订单明细包后，认账及分账列表和任务详情缓存会立即失效并刷新，避免继续显示旧快照。
- 重传订单明细包后，会刷新同账单日、同规则下所有任务快照，清理空任务残留的旧明细条数。
- 删除订单明细包时，任务快照统计限定当前任务自己的来源订单明细，避免同日同规则明细重复计入其它流水任务。

## 认账及分账

- 明细认账完成写回任务快照时，订单明细数量、金额、待拆分数量按当前任务口径保存，避免同日汇总模式把同一订单明细写到多个流水任务。
- 日期汇总仍按任务快照汇总，不改为列表实时计算。
- 任务详情“未认账”改为使用快照中的 `未认账 + 未认账中待拆分`，不再用总条数减已认账推导。

## 明细认账规则和上传

- 延续 v9.70：明细分账上传字段改为从明细认账规则的“分账包设置”维护和读取。
- “分账包设置”展示字号缩小；字段顺序为：认账条件字段、收入字段、明细匹配字段。

## 数据库迁移

- 本版不新增数据库迁移。
- 如果目标环境尚未部署 v9.70，需要先执行 `migrate-v9.70-detail-split-rule-upload-fields.sql`。
- 已执行过 v9.70 迁移的环境，直接部署 v9.71 代码即可。
