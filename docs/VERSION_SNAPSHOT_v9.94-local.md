# v9.94-local 版本快照

## 发布范围

- 本版用于新增财务凭证信息配置、按凭证模板生成收入凭证、优化凭证汇总与入账结果制单状态展示，并补充订单明细包、到账信息和认账规则编辑体验。
- 右上角系统版本号更新为 `v9.94`。
- 部署包：`releases/finance-platform-v9.94-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 财务凭证

- 新增“财务凭证信息”菜单，位于“认账信息设置”下方，包含“凭证模板”和“变量解释”。
- 凭证模板分为“到账认账模板”和“明细认账模板”，支持编辑并保存到数据库。
- 制单时改为按财务凭证信息中的模板生成凭证；模板第 1 行作为汇总行只生成一次，第 2、3 行按每条入账结果生成。
- 凭证详情标题调整为“收入凭证 - ID”，凭证汇总菜单第一列为“凭证ID”，条目只显示 ID。
- 凭证详情展示已制单时保存的静态结果，不分页。
- 模板列为空时，生成凭证对应列保持为空，不再用 `-` 填充。
- `【凭证收入名称】` 取到账信息中的凭证收入名称；若未填写，则取到账别称。

## 入账结果与到账信息

- 入账结果按天汇总列表去掉已锁定、未锁定和操作列，“记录数”改为“入账条目数”，增加“已制单数”。
- 入账明细列表取消独立操作列，将锁定/取消锁定放到状态列三点菜单；已制单条目隐藏三点菜单，且不允许取消锁定。
- 到账信息删除无用的“制单摘要内容”，将“凭证收入名称”调整到与到账别称同一行，并提示不填写时制单取到账别称。

## 其他优化

- 订单明细包列表的上传信息列改为轻量“查看”按钮，点击后在需要手动关闭的弹层中查看当前信息。
- 编辑认账规则时，在规则基本信息模块下方增加“添加条件”按钮；新增条件后页面自动滚动到新条件输入位置。

## 数据库迁移

- 本版新增数据库迁移：`migrate-v9.94-voucher-template-settings.sql`。
- 已部署 v9.93 的环境升级到 v9.94 时，需要先执行该迁移，再部署新版代码。
