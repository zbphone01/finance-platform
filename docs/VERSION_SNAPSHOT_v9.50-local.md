# v9.50-local 版本快照

## 明细认账规则性能

- 编辑明细认账规则时，草稿保存改为 500ms 延迟合并写入，避免规则条件较多时每输入一个字符都同步写入完整草稿。
- 树形下拉选择器在关闭状态下不再遍历部门、预算编码、项目、NC 项目、平台项目、项目详情等大字典树。
- 树形下拉内部搜索使用延迟输入值，降低连续输入时的主线程压力。
- 以上优化用于缓解订单明细规则超过 40 条后，编辑“认账关键字字段”出现明显卡顿的问题。

## 到账认账规则性能

- 到账认账规则列表接口改为首屏只返回规则摘要和 `splitCount`，不再随列表返回完整分账 `splits`。
- 点击编辑或复制规则时，再按规则 ID 调用详情接口读取完整分账信息。
- 启用/停用到账认账规则新增轻量接口，只更新状态，不再走完整规则更新和分账重写流程。
- 以上优化用于降低打开到账认账页面时的列表接口数据量和前端渲染负担。

## 公益平台

- 新增平台项目名称时，重复提醒改为仅在“同公益平台 + 同 NC 项目 + 同平台项目名称”完全一致时触发。
- 重复提醒弹窗文案为“本平台已建该平台项目”，且只提供关闭按钮，不再提供继续添加确认。
- 新增平台项目名称的编号预填改为从后端实时生成最新 `PPxxxxxxx`，避免刚创建项目后再次新增时沿用旧编号导致保存失败。

## 数据库迁移

- v9.50 无新增数据库迁移。
- 部署前仍需确认 v9.45、v9.46、v9.47、v9.48 已完成迁移。
