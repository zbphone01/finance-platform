# v10.56-local 版本快照

## 发布范围

- `认账及分账` 页面原“已忽略订单”入口改名为“人工处理订单”，保留原内部路由，避免旧链接失效。
- 人工处理订单列表同时展示已忽略、已转移和已转移/已认账订单；热表与所有月归档表使用同一口径读取。
- 顶部汇总改为互斥的 `已忽略条数`、`已转移条数`、`已转移/已认账条数`。关键字和金额搜索会影响三项汇总，状态筛选只缩小列表结果，不改变三项总览。
- 列表增加 `全部状态 / 已忽略 / 已转移 / 已转移/已认账` 状态筛选；已转移订单存在 `match_result_id` 时显示“已转移/已认账”。
- 列表“忽略原因”列改名为“操作原因”，继续读取订单明细的 `ignore_reason`，统一展示忽略原因或转移原因。
- 状态筛选移到列表卡片右上方，“转移日期”按钮移到表格下方左侧；批量转移仍只允许选择未归档的 T+1 已忽略订单。
- 未认账的已转移订单可以从人工处理订单列表取消转移；已转移/已认账订单只读展示，不新增直接回滚认账入口。
- 人工处理订单和日期汇总订单明细在取消忽略、取消转移前，会检查订单原日期汇总对应银行流水是否已有认账结果；没有结果时直接恢复订单，存在结果时先弹窗展示原日期、取消范围、银行到账数、认账结果数和认账金额，确认后先取消认账再恢复订单。
- 联动取消认账沿用银行流水统一取消范围：普通流水取消该到账结果，同日汇总取消整个同日汇总任务，多日汇总取消已确认匹配组；当前账号没有取消认账权限，或任一结果已锁定、已生成凭证时禁止继续。确认提交时后端重新检查订单状态、权限和认账结果。
- 存在多套凭证模板需要选择时，制单弹窗标题改为“请选择凭证模版”，流水提示改为“银行流水号”，并精简模板选择区域；不需要选择模板时继续显示“填写制单信息”。
- 右上角系统版本号更新为 `v10.56`。
- 部署包：`releases/finance-platform-v10.56-local.tar.gz`，包含本地验证通过的预构建 `dist/`，服务器不执行 Vite/esbuild 构建。

## 数据库、依赖与配置

- 本快照只记录从 v10.55 升级到 v10.56 的变化。
- 本版本复用 `bill_details.operation_status`、`bill_details.match_result_id` 和 `bill_details.ignore_reason`，不新增数据库结构迁移，不执行 SQL，也不执行 `drizzle schema push`。
- 本版本不新增 npm 依赖、环境变量或运行配置。
- v10.55 及更早版本要求的数据库结构与迁移必须已经完成；本版本不重复执行历史迁移。

## 风险与回退

- “已转移条数”只统计尚未生成入账结果的已转移订单；已经生成入账结果的订单单独进入“已转移/已认账条数”，三项汇总不重复计数。
- 人工处理订单列表会合并热表和月归档表；归档订单继续只读，不允许批量转移或取消操作。
- 已转移/已认账订单不在人工处理订单列表提供取消转移，避免从该入口触发认账任务回滚；需要取消认账时继续从日期汇总银行流水统一入口处理。
- 取消忽略或取消转移触发的认账回滚可能覆盖整组同日汇总或多日汇总结果，弹窗中的取消范围、结果数和金额必须核对后再确认；已生成凭证或已锁定结果需先解除对应状态。
- 代码可使用 `releases/finance-platform-v10.55-local.tar.gz` 回退；本版本没有数据库结构变化，不需要数据库回滚。
- 回退后入口恢复为“已忽略订单”，不再展示已转移订单和三类状态汇总；凭证模板选择弹窗恢复 v10.55 样式。
