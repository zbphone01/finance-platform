# v10.55-local 版本快照

## 发布范围

- `认账及分账 / 日期汇总 / 银行流水` 作为银行流水取消认账的统一入口：普通流水取消该到账的全部认账结果，同日汇总取消整个任务，多日汇总取消当前确认组。
- 已认账或部分认账流水继续显示取消认账；`已认账/已制单` 状态不再显示取消认账，避免用户进入必然被凭证锁定拦截的操作。取消确认查询和提交仍会重新校验锁定与凭证状态。
- `入账结果 / 入账明细` 状态菜单移除按单条入账结果取消认账，只保留锁定和取消锁定；日期汇总订单明细中的单条手动认账取消入口保持不变。
- 删除没有前端调用的旧版 `result.cancelManualRecognition` 接口、专用状态刷新函数和无用导入，统一使用日期汇总银行流水的完整取消逻辑。
- 右上角系统版本号更新为 `v10.55`。
- 部署包：`releases/finance-platform-v10.55-local.tar.gz`，包含本地验证通过的预构建 `dist/`，服务器不执行 Vite/esbuild 构建。

## 数据库、依赖与配置

- 本快照只记录从 v10.54 升级到 v10.55 的变化。
- 本版本不新增数据库结构迁移，不执行 SQL，也不执行 `drizzle schema push`。
- 本版本不新增 npm 依赖、环境变量或运行配置。
- v10.54 的 `bill_details` 主表旧去重唯一索引清理必须已经完成；本版本不重复执行 v10.54 迁移。

## 验证结果

- `npm test` 通过：31 个测试文件、163 项测试。
- 取消认账范围单元测试通过：10 项测试。
- `npm run check` 通过。
- `npm run build` 通过，已生成生产环境 `dist/`。
- `git diff --check` 通过。
- 发布包按仓库发版规则检查预构建产物、迁移脚本和排除项。

## 风险与回退

- 入账结果页不再提供按一次认账分账组精细取消；需要取消认账时必须进入对应日期汇总，从银行流水状态按整条到账、同日汇总任务或多日确认组执行。
- 已锁定或已生成凭证的认账结果继续禁止取消；`已认账/已制单` 状态不显示取消入口，需要回滚时先按现有流程取消凭证或锁定。
- 删除的旧 `result.cancelManualRecognition` 接口没有仓库内调用方；部署后已打开的旧页面应刷新，避免继续使用旧前端资源。
- 代码可使用 `releases/finance-platform-v10.54-local.tar.gz` 回退；本版本没有数据库结构变化，不需要数据库回滚。
