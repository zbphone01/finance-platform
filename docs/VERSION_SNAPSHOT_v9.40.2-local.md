# v9.40.2-local 版本快照

## 认账任务状态

- 订单明细上传完成后，如果自动明细认账进入队列，任务会先标记为 `processing` 并刷新日期汇总。
- 手动点击日期汇总列表的“开始认账”时，待入队的明细认账任务同样先显示为“认账执行中”。
- `认账及分账` 日期汇总列表在存在“认账执行中”任务时每 15 秒自动刷新，任务结束后自动切回最终状态。

## 订单明细包

- 修复订单明细 CSV 流式解析在 UTF-8 中文字符跨流块边界时把商品名称写成 `�` 的问题，避免预匹配因乱码失败。
- 列表中的“来自文件”列改为紧凑展示并按内容自适应宽度；状态列不再固定，仅保留右侧操作列固定。
- 固定操作列增加实色背景与遮罩，横向滚动时不再透出其他列内容。
- 操作列在存在未匹配明细时显示“查看未匹配明细”入口。
- 明细页统一使用紧凑格式展示完整内容，避免字段被省略号截断。
- 删除大数据包时前端展示处理中状态，完成后自动刷新列表。
- 多来源文件组成的数据包支持选择删除整个数据包，或只删除某个来源文件的明细。
- 按实际删除范围回滚对应认账结果；已有制单结果仍阻止删除。

## 分账联动

- 收入部门先约束预算编码候选项。
- 预算编码关联多个 NC项目时，NC项目树只显示可选项目，不再展示不可选分支。
- 编辑规则时，预算编码新增关联 NC项目后可以实时选到新的关联项目，不再要求先保存规则后重新编辑。
- 平台项目名称继续按预算编码对应公益平台与当前 NC项目筛选。

## 公益平台

- 公益平台页面搜索去掉仅命中公益平台名称的结果，聚焦平台项目名称和项目详情。
- 平台项目名称命中搜索词时，其下项目详情一并展示，避免误显示“暂无项目详情”。
- 主内容区收敛为视口内滚动容器，搜索框随公益平台列表滚动固定在顶部。
- “添加平台项目名称”快捷入口只在每个公益平台最后一个平台项目名称区域末尾出现；最后一项有展开详情时，入口放在详情之后。

## 到账信息汇总

- 编辑已被明细认账规则引用的到账别称时，同步更新规则中的匹配到账信息别称引用。
- 已被规则使用的明细认账到账信息不允许直接改成到账认账，避免规则执行链路断开。
- 对历史上已经失效的到账别称引用，规则编辑页回显旧别称并提示重新选择，不再显示为空。

## 数据库

- 本次功能修订没有新增数据库结构迁移。
- 当前发布线包含 `migrate-v9.40-recognition-summary-variance-diff.sql`，用于修正已有日期汇总差异金额；若线上尚未执行 v9.40 迁移，部署本版本前需先执行。
