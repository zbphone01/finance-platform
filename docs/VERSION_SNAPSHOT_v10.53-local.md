# v10.53-local 版本快照

## 发布范围

- 数据库重任务队列新增跨应用实例互斥：同一业务数据库上的多个应用实例通过 MySQL 命名锁串行执行重任务，并保留认账任务的优先等待协议，避免上传、认账和汇总任务跨进程并发压垮数据库。
- 明细分账大文件解析完成后按每 5000 行分批入库，所有批次保持在同一事务中；入库失败时回滚并把文件状态更新为失败，同时保存失败原因。
- 预算编码编辑部门弹窗的关联部门改为树形多选，支持搜索、逐项勾选、清空和完成，并排除当前部门自身。
- 认账及分账菜单的已认账流水统一支持取消认账：普通到账取消该到账的全部认账结果，同日汇总取消整个任务，多日汇总取消当前确认组；存在锁定或已制凭证结果时禁止取消。
- 取消认账后统一刷新银行流水、认账任务和日期汇总状态；已归档订单明细会先在归档锁内恢复到热表，再按原认账范围回滚。
- 凭证模板的四类业务模板均支持维护多套具名模板，并提供新增、改名、复制和删除；模板编辑区改为紧凑的表格式布局，每套模板仍固定三行。
- 单笔制单遇到相关业务类型存在多套模板时，先弹窗选择模板名称，再按所选模板生成凭证；只有一套模板时保持直接制单。
- 批量制单不弹出模板选择，只处理无需人工选模板的到账；跳过的普通到账、同日汇总或多日汇总范围不会部分制单，完成后提示已制单数量和需人工处理数量。
- 到账认账“认账时填写”的分账表格按内容自适应前三列列宽，预算编码恢复正常字号显示。
- 操作指引调整明细分账步骤顺序，并补充“认账时填写”规则的人工认账说明。
- 右上角系统版本号更新为 `v10.53`。
- 部署包：`releases/finance-platform-v10.53-local.tar.gz`，包含本地验证通过的预构建 `dist/`，服务器不再执行 Vite/esbuild 构建。

## 数据库、依赖与配置

- 本快照只记录从 v10.52 升级到 v10.53 的变化。
- 本版本不新增表、字段或索引，不需要执行 SQL 迁移，也不执行 `drizzle schema push`。
- 多套凭证模板使用现有 `voucher_template_settings` 表保存新的 `template_sets_v2` 配置键；旧版单模板配置继续保留，便于代码回退，无需数据库结构变更。
- 跨应用数据库重任务锁复用现有 `DATABASE_URL` 建立独立 MySQL 连接，不新增环境变量、不新增 npm 依赖。
- 本版本不调整运行配置。
- v10.48 的月归档索引灰度和正式清理不是本版迁移，继续按 `docs/DEPLOY_v10.48-local.md` 的数据库状态与观察窗口独立执行。

## 风险与回退

- 同一数据库的重任务会主动串行等待；任务高峰期可能延长排队时间，这是用于保护数据库的设计行为。命名锁连接或任务异常时必须释放锁和独立连接。
- 明细分账批量入库使用单一事务；任一批次失败会回滚全部分账条目，并保留失败文件记录和原因供重试排查。
- 流水状态栏的取消认账范围有意扩大：普通到账取消整条到账，同日汇总取消整任务，多日汇总取消确认组。操作前需根据确认弹窗核对范围。
- 批量制单遇到需人工选择模板的范围会整组跳过，不会在同一到账或汇总范围内只生成部分凭证。
- v10.53 创建的额外凭证模板保存在 `template_sets_v2`；回退 v10.52 后旧代码会忽略这些额外模板并继续读取保留的旧版默认模板，额外模板数据不会被删除。
- 代码可使用 `releases/finance-platform-v10.52-local.tar.gz` 回退；本版本没有数据库结构变更，不需要数据库回滚。
- 部署脚本使用本轮固定 `dist` 备份原子切换；暂存校验、启动或 HTTP 健康检查失败时恢复本轮部署前产物。
