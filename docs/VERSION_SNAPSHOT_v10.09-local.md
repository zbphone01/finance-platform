# v10.09-local 版本快照

## 发布范围

- 本版用于优化凭证汇总筛选、收入凭证详情说明浮层和凭证行说明数据。
- 右上角系统版本号更新为 `v10.09`。
- 部署包：`releases/finance-platform-v10.09-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 凭证汇总

- `凭证汇总` 的流水状态筛选改为：`全部状态`、`未认账`、`已认账`、`已认账/已制单`。
- `已认账` 筛选只展示已认账但尚未关联凭证的流水。
- `已认账/已制单` 筛选只展示已认账且已关联凭证的流水。
- 列表第一列表头改为 `流水日期`。

## 收入凭证详情

- `财务凭证信息` 中每个凭证模板三行固定解释为：
  - 第一行：凭证总览。
  - 第二行：项目资金行。
  - 第三行：管理费行。
- 收入凭证详情页仅项目资金行和管理费行支持点击打开说明浮层；凭证总览行不再触发浮层。
- 说明浮层字段保留：`结算方式`、`结算日期`、`收款渠道`、`年度`、`收款活动类型`、`项目名称`、`资金来源`、`项目筹款预算`、`部门`、`客户`、`渠道账户`。
- 已明确取值的字段按以下规则展示：
  - `结算日期`：凭证日期，即流水日期。
  - `收款渠道`：优先到账户名，否则使用凭证收入名称。
  - `年度`：流水日期年份。
  - `收款活动类型`：捐赠活动对应的活动说明编号。
  - `项目名称`：NC 项目原值，显示为 `编号_名称`。
  - `资金来源`：入账结果的支出资金来源。
  - `项目筹款预算`：入账结果的预算编码。
  - `部门`：入账结果的收入部门。
- 暂无取值规则的字段继续显示 `-`。

## 制单执行效率

- 本版不新增凭证说明快照字段，不需要数据库迁移。
- 说明浮层数据在打开收入凭证详情时按需读取和组装，不在制单生成时额外查活动字典或写说明快照，避免增加制单执行耗时。
- 若后续需要把这些说明内容传给其他平台，建议新增凭证行说明 JSON 快照字段，在制单时固化外传数据口径。

## 数据库迁移

- 本版无新增数据库迁移。
- 从 v10.08 升级到 v10.09 可直接部署代码包。
- 如目标环境尚未部署 v10.08，需要先按 v10.08 文档补齐 v10.00、v10.01、v10.02 迁移。
