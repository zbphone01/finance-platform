# v9.49-local 版本快照

## 订单明细上传

- 兼容支付宝账务明细导出的 CSV 文件。
- CSV 上传会自动识别 UTF-8 和 GB18030 编码，避免中文表头乱码导致识别失败。
- CSV 上传会跳过 `#支付宝账务明细查询`、账号、起止日期、分隔线等前置说明行，并从真实字段行开始读取。
- XLSX 上传同样支持跳过前置说明行，避免第一行不是字段名时导入失败。
- 上传时继续过滤汇总行、空行和非订单明细行。

## 字段兼容

- 订单明细仍必须满足规则配置的 `日期字段`、`收入字段`、`订单号字段`。
- 字段匹配新增常见别名和带单位表头兼容：
  - `时间` 可兼容 `发生时间`、`交易时间`、`下单时间`、`订单时间`。
  - `金额` / `收入金额` 可兼容 `收入金额（+元）`、`订单金额`、`实收金额`、`支付金额`。
  - `订单号` 可兼容 `商户订单号`、`订单编号`、`业务流水号`。
- 表头中的括号单位会参与规范化处理，例如 `收入金额（+元）` 可被规则字段 `收入金额` 命中。

## 规则匹配提醒

- 文件格式兼容只解决“能否正确读取并入库”的问题。
- 规则条件仍按配置的 `等于` / `包含` 执行。
- 如果规则条件为 `备注 等于 donation_10705`，但支付宝备注实际是 `公益宝贝捐赠=项目=店铺` 一类内容，则该规则不会匹配；需要把关键字改成文件中的实际备注内容，或改用 `包含` 匹配。
