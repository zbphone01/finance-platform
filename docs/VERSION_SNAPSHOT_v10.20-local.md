# v10.20-local 版本快照

## 发布范围

- 本版聚焦手动认账分账交互、手动认账制单收款渠道和财务凭证信息菜单文案。
- 右上角系统版本号更新为 `v10.20`。
- 部署包：`releases/finance-platform-v10.20-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 手动认账

- 手动认账去掉认账类型切换，分账设置沿用到账认账字段选择和交互。
- 分账设置中的“分账比例%”改为“分账形式”，支持选择 `百分比` 或 `金额` 并填写对应数值。
- 添加分账按钮改为到账认账规则同款虚线按钮样式，单独占一行，取消和确认认账按钮保留在下方。
- 添加分账时自动沿用已有分账的分账形式；非首条分账的分账形式不可修改。
- 确认认账时，认账金额校验使用浏览器弹窗提示；分账合计校验失败使用需要点击 `知道了` 关闭的弹窗提示。
- 分账合计校验按分账形式区分：
  - `百分比`：各分账百分比合计必须等于 `100%`。
  - `金额`：各分账金额合计必须等于认账金额。
- 分账设置默认只显示 `分账形式` 和 `收入类型`；选择收入类型后，再按实际类型展示后续字段。
- `捐赠来源` 只在收入类型为 `捐赠收入` 时显示。
- 到账认账中的手动认账选择 `捐赠收入` 时，捐赠来源默认 `银行直捐`。
- 订单明细认账中的手动认账选择 `捐赠收入` 时，捐赠来源默认 `互联网募捐平台`。

## 制单收款渠道

- 手动认账在认账金额和分账设置之间新增 `收款渠道` 下拉，选项与到账信息中的 `凭证收款渠道` 一致。
- 手动认账提交时保存收款渠道编号到入账结果，仅用于后续制单，不在前端入账结果列表展示。
- 制单时优先使用手动认账保存的收款渠道；没有值时继续沿用到账信息配置兜底。
- 财务凭证信息下的菜单和管理页文案由 `收入渠道管理` 调整为 `收款渠道管理`。

## 数据库迁移

- 本版新增迁移：`migrate-v10.20-manual-recognition-voucher-receipt-channel.sql`。
- 该迁移为 `match_results` 新增 `voucher_receipt_channel_code` 字段，用于保存手动认账制单收款渠道编号。
- 本地数据库已执行该迁移，并确认字段存在。
- 如果目标环境尚未部署 v10.19，需要先按 v10.19 文档补齐 v10.16-v10.19 迁移。
