# v10.14-local 版本快照

## 发布范围

- 本版用于新增凭证收款渠道基础数据维护，并优化账号、手动认账、银行到账上传和日期汇总返回体验。
- 右上角系统版本号更新为 `v10.14`。
- 部署包：`releases/finance-platform-v10.14-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 凭证收款渠道

- `到账信息汇总` 页签栏新增 `凭证收款渠道`。
- 支持维护一组基础数据：`收款渠道编号`、`收款渠道名称`。
- 收款渠道编号唯一，重复保存会提示错误。

## 账号管理

- 编辑账号并重置密码后，复制新密码增加兼容逻辑。
- 当内嵌浏览器阻止 Clipboard API 时，会回退到临时文本框复制，减少“复制失败”。

## 认账及分账

- 日期汇总列表页码写入 URL。
- 在第 N 页点击查看日期汇总后，详情页返回会回到原页码。
- 添加银行到账弹窗会预加载 XLSX 解析组件，并展示加载/上传处理状态，避免大文件解析阶段无反馈。

## 手动认账

- 手动认账选择 `银行直捐` 且收入类型为 `利息` 时，反馈类型、支出资金来源、地区、匿名、会员姓名和管理费均可不填。
- 前端对应控件置灰；后端按空值和 0 管理费落库。
- 入账结果中该类利息的项目资金和管理费展示为 `-`。

## 数据库迁移

- 从 v10.13 升级到 v10.14 需要执行：
  - `migrate-v10.14-voucher-receipt-channels.sql`
- 该脚本新增 `voucher_receipt_channels` 表，用于维护凭证收款渠道。
- 如果目标环境尚未部署 v10.13，需要先按 v10.13 部署说明补齐订单明细分区迁移。
