# v9.48-local 版本快照

## 明细认账规则

- 明细认账规则条件新增 `匹配方式`，选项为 `等于`、`包含`。
- 历史规则迁移后默认 `等于`。
- 明细认账上传匹配和手动补匹配均按条件配置执行：`等于` 使用精确匹配，`包含` 使用包含匹配。
- 条件重复判断改为按 `认账关键字字段 + 关键字` 判断；重复时提示具体条件号，阻止保存。

## 订单明细上传

- 上传订单明细时，必须包含规则中配置的 `日期字段`、`收入字段`、`订单号字段`。
- 这三个字段按列名精确匹配，不再使用兼容列名兜底。
- 缺少任意字段时直接提示缺列并取消入库。

## 规则条件导入导出

- 条件 CSV 新增 `匹配方式` 列。
- 导入 CSV 如果缺少 `匹配方式` 列，会直接提示缺列并取消入库。
- 同一条件序号的多行必须保持 `关键字字段`、`匹配方式`、`关键字` 一致。

## 数据库迁移

- 新增迁移脚本 `migrate-v9.48-detail-keyword-match-type.sql`。
- 迁移为 `rule_items` 新增：
  - `keyword_match_type`

## 验证

- `npm run check` 通过。
