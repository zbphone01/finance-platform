# v9.73-local 版本快照

## 发布范围

- 本版用于替代 v9.72-local 包，包含银行流水取消认账和日期汇总银行流水列表交互优化。
- 部署包：`releases/finance-platform-v9.73-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 认账及分账

- 日期汇总银行流水列表中，到账认账或手动认账完成的已认账流水支持取消认账。
- 取消认账入口改为状态后的三个点菜单，避免在列表中直接展示醒目的操作按钮。
- 已认账流水点击取消认账时，会弹窗确认；确认后回滚该银行到账为未认账。
- 部分手动认账流水可按手动认账记录选择取消，取消选项展示“预算编码 + 金额”。
- 对“已有明细认账，又手动补认账”的混合场景，只取消所选手动认账金额，不影响原有明细认账结果。
- 已制单的入账结果不允许取消认账。
- 银行流水列表的“认账差额”列改为仅在当前列表存在差异金额时显示并固定；无差异时隐藏该列，状态列直接固定在最右侧。

## 数据库迁移

- 本版不新增数据库迁移。
- 如果目标环境尚未部署 v9.70，需要先执行 `migrate-v9.70-detail-split-rule-upload-fields.sql`。
- 已执行过 v9.70 迁移的环境，直接部署 v9.73 代码即可。

## 验证

- `npm run check` 通过。
- `npm run build` 通过。
- 发布包完整性检查通过，沿用历史轻量发布方式，不包含本地 `dist`，由服务器部署脚本重新构建。
- 发布包未包含 `node_modules`、`.upload-cache`、`releases` 等本地大目录。
