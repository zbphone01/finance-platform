# v10.02-local 版本快照

## 发布范围

- 本版用于优化凭证汇总、凭证详情、入账明细展示，以及到账上传时的忽略流水提示。
- 右上角系统版本号更新为 `v10.02`。
- 部署包：`releases/finance-platform-v10.02-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 认账及分账

- 添加银行到账时，如存在被忽略的重复流水，完成弹窗展示忽略流水明细：日期、流水号、金额。

## 凭证汇总

- 列表表头调整为：流水日期（同凭证日期）、银行流水、到账金额、流水状态、凭证ID、凭证金额、操作。
- 每页显示 50 条，按时间倒序排列。
- 支持按日期范围和银行流水状态筛选。
- 列表按银行流水拼装；未制单的流水，凭证ID和凭证金额显示 `-`。
- 多笔到账生成同一凭证时，银行流水列展示多条流水，到账金额展示合计。
- 凭证金额只取借方合计；借方为空时显示 `-`。

## 凭证生成与详情

- 制单时，入账结果包含订单退款时，将捐赠收入与订单退款按同一组凭证信息合并生成。
- 合并后订单明细数、项目资金和管理费按捐赠收入与退款订单合计计算。
- 凭证详情页列表底部增加总计行，每次打开详情实时计算借方金额和贷方金额。
- 凭证详情每行可点击，点击行高亮，并在摘要列横向位置展示小字体核对浮层。

## 入账结果

- 入账结果新增“认账类型”字段。
- 到账认账按到账认账规则保存认账类型；明细认账保存为“渠道捐赠”。
- 入账明细列表在流水号与收入类型之间展示认账类型。
- 入账明细列表表头使用小号字；预算编码、支出资金来源列内容使用标准小号字。

## 数据库迁移

- 本版新增数据库迁移：
  - `migrate-v10.01-voucher-summary-flow-index.sql`
  - `migrate-v10.02-match-result-recognition-type.sql`
- 已部署 v10.00 的环境，部署 v10.02 代码前需要按顺序执行 v10.01、v10.02 迁移。
- 如果目标环境尚未部署 v10.00，需要先补齐 `migrate-v10.00-bank-flow-recognition-status.sql`，再执行本版迁移。

## 本地验证

- `npm run check` 通过。
- `npm run lint` 通过。
- `npm run build` 通过。
