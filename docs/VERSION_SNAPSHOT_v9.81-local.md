# v9.81-local 版本快照

## 发布范围

- 本版用于替代 v9.80-local 包，提前放置制单相关菜单和操作入口，并将原入账结果“制单状态”文案调整为“锁定状态”。
- 部署包：`releases/finance-platform-v9.81-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 入账结果锁定

- 入账结果页原 `已制单 / 待制单` 展示调整为 `已锁定 / 未锁定`。
- 原单条 `制单 / 取消制单` 操作调整为 `锁定 / 取消锁定`。
- 原按天 `批量制单 / 取消批量制单` 操作调整为 `批量锁定 / 取消批量锁定`。
- 删除、取消认账等保护提示同步改为锁定口径，避免与后续真正的制单功能混淆。

## 制单入口占位

- `认账及分账` 日期汇总列表操作列新增 `批量制单` 图标占位，放在删除按钮左侧；当前禁用，仅提示功能开发中。
- 日期汇总详情的银行流水列表中，状态为 `已认账` 的流水在状态后展示制单图标占位；未认账、部分认账、执行中状态不展示。
- 左侧菜单新增 `制单结果`，放在 `入账汇总` 下方，页面当前展示开发中提示。

## 财务信息设置

- 左侧菜单新增一级菜单 `财务信息设置`，放在 `认账信息设置` 下方。
- 当前为灰色禁用占位，不跳转页面。

## 数据库迁移

- 本版不新增数据库迁移。
- 已部署 v9.80 的环境可直接部署代码。
- 从 v9.79 或更旧版本升级时，仍需先按 `docs/finance-recon-SKILL.md` 的“数据迁移”段补齐缺失迁移。

## 验证

- `npm run check` 通过。
- `npm run build` 通过。
- `git diff --check` 通过。
- 发布包完整性检查通过，沿用历史轻量发布方式，不包含本地 `dist`，由服务器部署脚本重新构建。
