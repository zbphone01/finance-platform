# v10.48-local 版本快照

## 发布范围

- 利息认账的支出资金来源不再由到账认账规则或手动认账填写，前后端统一保存为 `非限定性-利息收入`。
- 凭证模板菜单新增 `利息收入` 三行模板，支持模板变量 `【利息信息】`。
- 利息由填写文本凭证 ID 改为自动模板制单；逐笔制单必须填写利息信息，弹窗实时预览摘要，服务端同步校验必填和 500 字长度上限。
- 利息凭证明细行的客户档案固定为 `北京市企业家环保基金会`，收款活动类型固定为 `801_其他收入`；历史利息手工凭证仍可取消，取消后重新制单改走自动模板。
- 批量制单不会代填利息信息，包含待制单利息的银行流水会跳过并提示逐笔处理。
- 凭证汇总行的银行账户改为读取所选银行流水关联账号的 `bank_accounts.account_alias`，未关联账号或别称为空时显示 `-`；历史凭证快照不回填。
- 凭证明细行浮层字段按 `年度 / 部门 / 客户档案 / 收款渠道 / 收入预算 / 项目名称 / 资金来源 / 收款活动类型` 展示，删除结算日期和渠道账户。
- 明细浮层的客户、项目筹款预算分别更名为客户档案、收入预算；历史凭证读取时兼容旧字段名。
- 明细浮层项目名称直接保存完整 NC 项目原值，显示为 `编号_NC项目名称`；模板变量 `【NC项目名称】`继续使用不带编号的名称。
- 月归档订单明细索引采用两阶段精简：首阶段把三个候选索引设为不可见，观察稳定后第二阶段正式删除并释放空间。
- 右上角系统版本号更新为 `v10.48`。
- 部署包：`releases/finance-platform-v10.48-local.tar.gz`，包含本地验证通过的预构建 `dist/`，服务器不再执行 Vite/esbuild 构建。

## 数据库与迁移

### 升级范围

- 本版本包含两个迁移脚本：
  - `migrate-v10.48-archive-index-canary.sql`：首发必须执行的灰度迁移。
  - `migrate-v10.48-archive-index-finalize.sql`：灰度观察 3–7 个业务日后才能执行的正式清理迁移。
- 本快照只记录从 v10.47 升级到 v10.48 所需的数据库变化。
- 首次部署 v10.48 时只执行灰度迁移，禁止连续执行两个脚本。
- 本版业务代码不新增数据库表或字段；凭证模板继续保存于 `voucher_template_settings.templates` JSON，不需要结构迁移。
- 本版不新增 npm 依赖、不调整运行配置、不执行 `drizzle schema push`，部署脚本不会自动执行 SQL。

### 灰度迁移变化

- 对每张 `bill_details_archive_YYYYMM` 月归档表校验替代索引完整后，将以下索引设为 `INVISIBLE`：
  - `bd_order_file_idx`
  - `bd_task_status_idx`
  - `bd_rule_detail_split_status_idx`
- 不删除既有月归档表的上述索引，不在灰度阶段释放索引空间。
- 新建月归档表不再无条件保留热表全部索引；若同时继承新旧两套唯一索引，保留 `bd_rule_bill_date_bill_no_partition_uq`，删除旧的重复唯一索引。
- 新建月归档表的三个候选索引同样先保持不可见。
- 新增辅助过程 `normalize_bill_details_archive_indexes_v1048`，并替换 `ensure_bill_details_archive_month_table` 的月表创建逻辑。

### 正式清理变化

- 正式清理脚本要求灰度辅助过程存在，并拒绝在任一候选索引仍可见时执行。
- 脚本先完整校验全部月归档表和替代索引，再删除三个不可见候选索引。
- 删除完成后，未来新建月归档表直接删除这些热表专用或重叠索引。
- 正式清理会实际释放索引空间，属于不可直接逆转的结构操作。

## 风险与回退

- 目标环境缺少 v10.47 的 `bank_accounts` 表或 `bank_flows.bank_account_id` 时，必须先按 v10.47 部署说明补齐，不能直接执行本版代码。
- 旧银行流水的 `bank_account_id` 为空时，凭证汇总行银行账户仍显示 `-`；设置默认账号不会自动回填历史流水或历史凭证快照。
- 新模板未配置有效凭证行时，利息自动制单会提示维护对应模板，不会生成空凭证。
- 灰度期间不可见索引仍占用空间并参与写入维护；出现查询回退或业务异常时，应停止正式清理并按月表逐一恢复候选索引可见性。
- 正式清理后索引已被删除，不能通过改回可见性恢复；如需回退必须根据本版记录的索引定义另行制定重建脚本。
- 部署脚本使用本轮固定 `dist` 备份原子切换；暂存校验、启动或 HTTP 健康检查失败时恢复本轮部署前产物。发布包缺少预构建 `dist` 时会在修改线上文件前停止。
- 代码可以使用 `releases/finance-platform-v10.47-local.tar.gz` 回退；v10.48 保存的凭证模板 JSON 和凭证快照可以保留，旧代码会忽略未知模板项。
- 历史已生成凭证继续读取 `voucher_result_lines.explanation_json` 快照，不因代码回退或基础资料变化自动重算。
