# v9.62-local 版本快照

## 发布范围

- 本版用于替代 v9.61-local 包，包含打包明细规则字段可空、双空字段全量入库追查、打包明细快速差异预检和明细认账规则列表不分页。
- 部署包：`releases/finance-platform-v9.62-local.tar.gz`。
- 推荐继续使用 `deploy-update-optimized.sh` 部署。

## 打包明细规则

- 当匹配到账信息选择的是打包明细时，日期字段允许为空，保存后不再自动回填为 `时间`。
- 当匹配到账信息选择的是打包明细时，订单号字段允许为空，保存后不再自动回填为 `订单号`。
- 非打包明细仍保留原默认字段：日期字段默认 `时间`，订单号字段默认 `订单号`。
- 规则创建页已同步调整必填提示和说明文案。

## 打包明细上传

- 打包明细主要使用匹配日期入库，日期字段为空时不再因为缺少订单明细日期跳过数据。
- 打包明细订单号字段为空时，不再因为缺少订单号跳过数据。
- 上传打包订单明细时，如果日期字段和订单号字段都为空，会保留明细文件中所有非空列到原始数据，方便后续追查问题。
- 上传阶段不再因为候选到账已经有认账结果而排除该到账，多个打包明细包可以继续指向同一笔银行到账。

## 打包明细认账和差异提示

- 多个打包明细包指向同一银行到账时，不再用最新包的认账结果顶替原认账结果，而是在原部分认账基础上继续判断。
- 认账前依旧先执行订单总额与到账剩余可认账金额对比；金额不足时只记录差异并进入差异状态。
- 无条件整包打包明细新增快速差异预检：按同一到账别称、匹配日期、打包明细汇总订单包缓存金额，再结合银行到账和已有认账结果计算差异。
- 快速差异预检在补匹配前执行，金额明显不足时不再进入大量明细计算。
- 当前版本不会自动修复已经被旧逻辑写入的历史超额认账结果；这类 pending 结果需要确认后单独回滚。

## 明细认账规则列表

- 明细认账规则列表取消分页，一次展示全部规则。

## 数据库迁移

- 本版不新增数据库迁移。
- 部署前需确认目标环境已完成 v9.59 迁移：
  - `migrate-v9.59-detail-split-files.sql`
  - 如线上缺少 `exclude_order_enabled`，需补跑前置检查项 `migrate-v9.59-exclude-order-rule.sql`。
